# 共通確認ダイアログ

選択を伴う確認には、元画面の中央へ重ねる共通の2択ダイアログを使う。ログ削除、記録の一時停止・停止、SDのFAT32フォーマット、設定初期化、USBモードへの切替と終了に適用する。

## 表示

画面サイズは240×135ドットとする。元画面の黒以外の画素を暗灰にして背景として残し、中央に黒地のウインドウを置く。ウインドウはx=8、幅224ドット、上下だけに白い1ドット線を描き、縦枠は付けない。質問を黄、対象や注意書きを白、選択中の矢印と項目をシアンで描く。取消は左、実行する操作は右に横並びで置く。操作できない項目は暗灰とし、その理由を赤で表示する。

通常のウインドウはy=38〜102、質問はy=44、補助情報はy=64、選択肢はy=80に置く。日本語は東雲16×16、英語はASCII 8×16を用いる。ファイル名と最下段の`[ENTER] CONFIRM`はASCII 8×8とする。文字や罫線を拡大・平滑化せず、画面のドットへ直接描画する。

ログ名は47文字までを省略せず表示し、27文字を超える場合は2行に分ける。このときウインドウをy=33〜107、質問をy=39、ファイル名をy=59 / 69、選択肢をy=85へ配置する。16ドットの注意書きを持つフォーマット・初期化確認はy=34〜106、質問をy=40、注意書きをy=60、選択肢をy=84とする。どの場合も背景のヘッダーと最下段のガイドを覆わない。

| 操作 | 日本語の選択肢 | 英語の選択肢 | 補助情報 |
|---|---|---|---|
| Live PlaceのF1 | 取消 / 一時停止 | Cancel / Pause | 質問で記録の一時停止を示す |
| GPS Loggerの停止 | 取消 / 停止 | Cancel / Stop | 質問で記録の停止を示す |
| LogsのD | 取消 / 削除 | Cancel / Delete | 対象ファイル名の全文 |
| FAT32フォーマット | 取消 / 実行 | Cancel / Confirm | SD全消去・NVS設定保持 |
| 設定初期化 | 取消 / 実行 | Cancel / Confirm | SDデータ保持 |
| USBモードへの切替 | 取消 / 切替 | Cancel / Switch | 再起動して切替。記録停止完了が必要 |
| USBモードの終了 | 取消 / 終了 | Cancel / Exit | PCの保存完了後に終了 |

## 操作と状態

開いた時は必ず取消を選択する。左右キーまたは`,` / `/`で選択する。左で取消、右で実行する操作を選び、端では折り返さない。Enterで選択中の項目を確定する。Esc / Delは選択中の項目に関係なく取消とする。上下キー、1/2/3、F1、Dなどは確認中に選択変更や別の操作を起動しない。画面消灯時間に達した場合は確認を閉じて消灯し、復帰キーで実行しない。

取消ではAppへ実行要求を作らない。操作を選択してEnterを押した場合だけ、確定済みの操作をUiModelが保持し、既存の通知・Appによる同期取得へ引き渡す。ダイアログを開いている間も元の記録は継続する。

ログ一覧の版が更新された場合は確認を閉じ、対象が入れ替わったまま確定できないようにする。同じ一覧で対象が記録中に変わった場合も削除を無効化し、取消へ戻す。Storage側の実行直前の保護検証も維持する。

## 実装

`application/task/ui/ChoiceDialog.h`が種類・選択・実行可否と共通キー操作を保持する。`UiModel::acceptDialog`は確定結果を既存のApp操作へ対応付け、`UiRenderer::drawDialog`がすべての確認を描画する。新しい確認を加える際も、この状態管理と描画を利用する。

背景の暗色化はUiCanvasの色変換で元画面を描く際に行い、追加のフレームバッファや通信キューを持たない。表示言語・キー割当の設定値編集は従来どおりSettings内で行い、この2択の確認とは別の操作とする。

検証結果は[共通確認ダイアログ検証](../検証/共通確認ダイアログ検証.md)を参照する。

USBモードの2確認も16ドットの補助文を持つため、ウインドウはy=34〜106、選択肢はy=84に配置する。USBモードの終了確認とその背後の画面では自動消灯を行わない。詳細は[起動モード・USBストレージ仕様](../09_起動モード・USBストレージ仕様.md)を参照する。

USBモードはメニューで起動し、終了確認は「ロガーへ戻る」またはメニューのEsc / Delから開く。PC公開中でも終了を有効にする。コピー・編集・保存完了後に確定し、Storageが実行中転送の完了とSD同期を待って公開を停止する。PCの未送信キャッシュは端末から同期できないため、Windowsのクイック削除以外の運用では安全な取り外しを先に行う。ログエクスポートの取り外し待機は同じ上下線の表現を使うが、2択ではなく取消だけを表示し、取り外し後は自動でログ選択へ進む。
