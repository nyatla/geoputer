# 画面画像の作成手順

## 1. Live Placeの採用仕様と現行実装

正本は[Live Place画面](live-place/README.md)と[レイアウト仕様](live-place/レイアウト仕様.md)の採用仕様1.3とする。住所2行、左の速度・進行方位、右のLAT / LON / ALT / SAT、記録詳細・赤帯、操作欄で構成する。地名と主数値は東雲16ドット、ラベル・単位・補助表示はC64 ASCII 8ドットとする。住所の例は習志野市庁舎の「千葉県 習志野市」「鷺沼2丁目1番1号」を使い、N03の例は1行目だけ、2行目は空欄とする。

画像は240×135 pxで直接描画し、各ピクセルを画面の1ドットへ対応させる。整数座標、アンチエイリアスなし、RGB565の色定義を使用する。プレビューだけ最近傍法で4倍とする。速度のm/h・km/h切替と丸め境界、数字3桁・小数点8ドット送り、符号付き経度11文字、電池100%、長い住所の省略、各GPS項目の未取得、赤帯、無効なF1を実寸で確認する。

2026-10-16のキー変更に合わせ、最下段右はFn不要の2を示す`2 MENU`とし、x=188・y=124へ描画する。全状態の画像を同じ実装から再生成し、この文字列を画素で検証する。

tools/render_live_place_layout.pyはUiRenderer / UiModel / PixelFont / Shinonomeを無改変でホスト実行し、採用仕様1.3の住所2行・左右・上下を均等分割したパネル、左上のSPD / HDGラベル、左端から中央縦線までのSPD / HDG間の横線を生成する。g++、Pillow、PlatformIOで導入済みのM5GFXを使用する。出力先live-place/のlive-place-refined-*.pngは実寸、*-preview.pngは4倍である。旧レイアウトのPNGはすべて同名の新レイアウト画像へ置き換え、1.1の画像を残さない。

通常、初期準備前、キャッシュ再構築、辞書読出し、ログ読出し・書込み、一時停止、SD保存失敗、GPS受信断、N03の住所を同じ描画規則で生成する。さらに数値の桁増加・表示上限・方位の周回・未取得・有効な0・電池100%・住所省略を検証用のシーンで描画する。これらの追加検証画像は一時ディレクトリだけに生成し、文書用の10状態と混在させない。RGの継続状態とSDの実I/Oの意味・色は維持する。入力値は配置確認用であり、接続中の実機の現在値や、ログ読出し等の機能実装完了を意味しない。

## 2. 更新と削除

仕様書だけを先に更新する段階では、新しい採用仕様と現行実装の版を区別し、旧画像を新仕様の採用画像として扱わない。描画実装を新レイアウトへ更新したら、すべての状態画像を同じスクリプトで再生成する。240×135 px、使用色、最近傍4倍、RG/SDの状態色、エラー帯の赤地・白文字、文書リンクを確認する。

旧案・旧実装のLive Place画像は残さず、参照リンクも採用仕様の画像へ更新する。旧名のPNG、過去版専用の状態画像、付随する古いメタデータを削除する。過去の画像生成プロンプトを現行仕様の代用として残さない。

旧入口`python3 doc/画面・操作/render_screens.py`はLive Place・Settings・ログビューアの現在の生成器へ委譲し、廃止した画像を再作成しない。

## 3. 生成器の範囲

ホスト描画の補助コードはtools/ui_preview_support.pyに置く。ASCIIのC64 8ドット・AsciiFont8x16と東雲16ドットを扱う。日本語8ドットの短い通知はこのAdapterの画像比較対象に含めず、翻訳文字列と実機の描画経路を区別する。LCDのバックライト輝度や撮影時の見え方までは再現しない。

Settingsは`python3 tools/render_settings_layout.py`で日本語・英語の各10状態を生成する。実装のUiRenderer / PixelFontを使用し、240×135 pxの40ファイル（実寸20枚・最近傍4倍20枚）をsettingsへ出力する。英語8×16、日本語16×16の字形・項目名と値の幅・罫線・ライセンス画面の言語間一致を検証する。変更前のライセンスフレームを保存済みなら、`--license-baseline <RGB565ファイル>`で元の画素との完全一致も確認する。現在の画面と検証結果は[Settings画面仕様](settings/README.md)と[Settings多言語化検証](../検証/Settings多言語化検証.md)を参照する。


Logs / Log Detail / Log PointとGPS Loggerの操作項目は`python3 tools/render_log_browser.py`で実装のUiRendererから日本語・英語各15状態を生成する。240×135の実寸と最近傍4倍の60枚をlogs / log-detail / gps-loggerへ配置する。既存名の画像は日本語版で更新し、英語版にはenを付ける。一覧6件、長いファイル名、端点・件数・サイズ、測位点、未取得値、読込中の表示保持、CRC不一致、空一覧、SDエラー、不完全な末尾、桁境界に加え、操作項目の日本語16×16 / 英語8×16を元の字形と画素比較する。右端・ヘッダー・フッターの画素境界も検査する。画像は配置確認用の入力であり、実機でのキー操作完了を意味しない。

Settingsの生成では、動作設定の全7項目・全選択肢を両言語で描画し、x=20の項目名と右端x=236の設定値を元の字形と画素比較する。選択項目と値の間隔、長い値、100%、言語名切替、消灯しない / Neverを含めて確認する。
