# Geoputer Boot画面

文書状態: 採用仕様 1.0（データセット異常時の起動継続は実装反映済み）
対象画面: 240 × 135 px、横向き  
入力: Cardputer ADV 56キーキーボード  

[画面・操作機能設計（共通仕様・画面一覧）](../02_画面・操作機能設計.md)

## 1. 目的と表示

起動時に各機能の準備状況を表示し、利用できない機能と理由を確認できるようにする。現在の実装段階では6項目を表示する。

データセットが使用できない場合も、以下のチェック一覧で理由を示した後にLive Placeへ進む。通常起動を続けることと、逆ジオコーディングが使用可能であることを区別する。原因・地名欄の文言・再検証条件は[データセット異常時の共通仕様](../../08_データセットメタデータ仕様.md#83-起動時の復元とエラー)を正本とする。

```text
GEOPUTER            STARTUP
------------------------------
[+] DISPLAY        240X135
[+] TASKS/QUEUES    4T/5Q
[+] NVS SETTINGS    LOADED
[!] SD CARD         NO CARD
[+] GPS UART        UART OK
[!] GALUCHAT DATA   NO SD
GPS:MESH  DATASET:01
------------------------------
F1 MAINT          ENTER START
```

文字はタイトルを含め8×8ドット、アンチエイリアスなしとする。ヘッダー下の罫線はy=22、チェック行はy=29から14px間隔の6行、GPS接続・データセット番号はy=110、フッター上の罫線はy=118とする。項目名と結果は別の列に配置し、結果の略称は9文字までとする。

| 項目 | 確認内容 | 主な結果 |
|---|---|---|
| DISPLAY | UIの240×135描画領域とフォントの準備 | 240X135 |
| TASKS/QUEUES | App・UI・GPS・Storageの4タスクと5キューの準備 | 4T/5Q、TASK ERR |
| NVS SETTINGS | 保存領域の準備、設定レコードの読込み・形式・検査値 | LOADED、DEFAULT、INVALID、NVS ERROR |
| SD CARD | カードの認識、マウントとFAT32判定 | FAT32、NO CARD、NOT FAT32、SD ERROR |
| GPS UART | Mesh KitのUART受信準備 | UART OK、UART ERR |
| GALUCHAT DATA | 保存済み番号・言語のファイル検出、Reader生成、ヘッダー・辞書形式・文字コード確認 | OPEN OK、NO SD、MISSING、MULTIPLE、CONFIG、VERSION、ENCODING、DATA ERR、TOO LARGE、NO MEMORY |

Galuchatの確認はGPS Fixを要求しない。データをRAMへ全展開せず、検索用のReaderを準備する。OPEN OKは起動時に必要な読出し準備の成功を表し、地図・辞書の全領域の走査や全地名の復号を完了した意味ではない。実検索中の読込異常はLive Placeへ別途表示する。

GPS UARTの成功は受信設定の準備までであり、GPS機器からのNMEA受信や測位成功を意味しない。GPS MODEはチェック行にせず、現段階の固定値MESHを補助表示する。GNSS PAUSEは未実装のため表示しない。GPSログはSTOPPEDのまま開始する。

## 2. 状態と色

| 表示 | 状態 | 色 |
|---|---|---|
| [.] | 未確認 | 暗灰 |
| [~] | 確認中 | シアン |
| [+] | 準備成功 | 緑 |
| [!] | 機能制限・確認を実施できない | 黄 |
| [X] | 準備・検証失敗 | 赤 |

NVS設定領域とSDの準備結果は分離する。SD未挿入・マウント失敗でもNVSの設定読込みを行う。設定が未保存の場合は初期値を使用し、DEFAULTとして正常表示する。設定が不正・読込不能ならエラーを表示し、初期値で継続する。SDが使用できない場合、GALUCHAT DATAはNO SDとし、未確認のデータを成功表示しない。

## 3. 完了と操作

確認中はCHECKING...とF1 MAINTを表示し、F1によるメンテナンス要求を除いて画面遷移・設定操作・無操作消灯を行わない。すべての確認結果が揃った時点で起動確認を完了し、各チェック行の成功・警告・失敗を保持してENTER STARTを表示する。データセットの警告・失敗も確認完了として扱う。

完了後は通常2秒、警告・失敗がある場合は5秒表示し、Live Placeへ自動遷移する。Enterは完了後だけLive Placeへの遷移要求として受け付ける。2・Esc・Del・上下左右ではBootを抜けない。Live Placeの無操作期限はBootを抜けた後から数える。

SD・NVS・GPS・Galuchatの障害は機能ごとに扱い、UIとAppが操作可能なら利用可能な機能で起動を継続する。画面やUIの準備に失敗してチェック画面そのものを表示できない場合は、シリアルログへ初期化失敗を出して停止する。処理自体の異常リセットは画面上の通常エラーと区別し、F1による読込み前の退避経路を用意する。

機能ごとの必要条件と複数障害時の制約は[システム構成設計7節](../../04_システム構成設計.md#7-エラー状態と機能の利用条件)に従う。GPS Fixなしは起動完了の待ち条件にせず、設定・既存ログの利用を禁止しない。SD利用不可でも有効FixがあればGPS情報を表示し、NVSが利用可能なら通常設定を保存できる。NVS設定が未保存ならDEFAULT、不正・復元失敗ならエラーと初期値適用を区別する。チェック行の赤・黄を理由に設定専用画面へ固定しない。

### 3.1 データセットが使用できない場合

NVSの番号と言語を復元して検証する。ディレクトリ・INI・GLC・言語セクション・Wordbookの欠落、不正なデータ、文字コード未対応、チャンク上限超過、メモリ不足、読出し失敗のいずれも通常起動の停止理由にしない。SDが利用不可ならSDのチェック行に媒体の理由を、GALUCHAT DATAにはNO SDを表示し、ファイル欠落と誤認しない。

すべての確認結果が揃った後は5秒表示し、期限満了またはEnterでLive Placeへ進む。F1は確認中・完了後ともメンテナンスを要求できる。データセット専用のSTARTUP ERROR画面や、上限超過・メモリ不足だけの全面警告は新仕様では使用しない。

Live Placeの地名2行へ原因を表示し、逆ジオコーディングを使用不可として保持する。GPS・設定・ログ閲覧を利用可能な範囲で継続し、SDが使えればGPSログを開始できる。SD利用不可の場合はログ保存も不可として別途表示する。選択番号・言語を別候補に自動変更せず、利用者が再マウント・適用・再起動を行った場合だけ再検証する。

## 4. タスク連携

Appが確認結果を集約し、SetUiScreen / UpdateUiContentでBootの値コピーをUIへ渡す。UIは描画とEnter・F1操作を担当し、初期化・SD・NVS・Galuchat読出しを直接実行しない。

NVS読込みはLoadSettings、Galuchat読出し準備はCheckDatasetの通知でStorageへ要求し、ReadCompleted / ReadFailedで結果を受け取る。未投入の要求だけを再試行し、投入済み要求を重複実行しない。通常起動の受付期間後はGPS受信を開始し、Boot表示中も継続する。

## 5. F1によるメンテナンス起動

F1（Fn＋1）はBootの確認中・完了後にメンテナンスを要求する。チェックに警告・失敗がある場合も同じ操作とし、データセット専用の起動停止画面は設けない。電源投入時から押し続けたF1は、最初のBoot画面を受け取る前でもUIが保持する。USBストレージとしての起動は、このキーで変更しない。記録の一時停止は0で行う。

AppはUIとStorageを先に起動する。NVS設定の読込み後に`config::BootMaintenanceWindowMs`（1500ms）の受付期間を置き、UIの操作要求を起動処理より優先する。F1が選ばれていればGPSタスクの開始とCheckDatasetの投入を省き、設定読込み完了後にSettingsへ移る。これにより、GLCや索引の読込みで再起動を繰り返す場合も、電源投入からF1を保持して自動読込みを避けられる。

受付期間を過ぎた通常起動ではGPS UARTとGaluchatを初期化する。Bootのフッターには常に`F1 MAINT`を表示し、確認中は`CHECKING...`、完了後は`ENTER START`を併記する。チェック結果が異常でもこのフッターを維持する。

メンテナンスは専用の実行状態として既存の設定画面を使い、入口タイトルを`MAINTENANCE`とする。自動消灯、Live Placeへの自動遷移、位置検索、GPS記録開始を行わない。設定変更、SD操作、データセット選択、USBモードへの切替は既存の処理を使用する。地図が使用不能でもその警告画面で設定を覆わない。設定入口でEsc / Delを押すと共通確認ダイアログを開き、取消／再起動を左右で選ぶ。再起動は取消を初期選択とし、Storageの処理中は実行を拒否する。子画面のEsc / Delは従来どおり一つ上へ戻る。

起動後のLive Placeでも、地名欄のデータセット異常または赤帯のエラー表示があり、記録がSTOPPEDで保存・セッション終了も完了している場合はF1からメンテナンスへ入れる。下部の`0 PAUSE`を`F1 MAINT`に置き換えて案内する。記録中・一時停止中はF1で状態を変更せず、GPS Loggerで停止してから入る。通常の2による設定画面は従来どおり利用できる。

すでに開始したStorageの読込みは強制中断しない。初期化中にF1を押した場合は新規の自動処理を止めて設定へ移るが、進行中の読込みはStorageが完了するまで所有する。読込み自体でクラッシュする場合は、次の起動時からF1を保持し、読込み前の経路を使用する。起動後に入った場合、すでに開始済みのGPS UART受信は継続するが記録・位置検索は行わない。

F1の入口、受付期間、メンテナンス状態、確認付き再起動に加え、データセット異常時の起動継続・地名欄表示への統一・再読込み抑止を実装した。索引保存・設定からの索引再生成は未実装。
