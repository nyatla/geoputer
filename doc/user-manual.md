# Geoputer 操作マニュアル

対象バージョン：v0.1.0

初回の書込み、microSDカード、マップセットの準備は[セットアップマニュアル](setup.md)を参照してください。本書はGPSロガーモードでの通常操作と、USB・Wi-Fi管理モードへの切替を説明します。

## 1. 起動と共通操作

通常起動ではGPS受信を開始します。**GPSログの記録は停止状態から始まります。** GPSが測位するまで、座標や地名は更新されません。地名と区域地図には、利用可能なマップセットの選択も必要です。

| キー | 通常の役割 |
|---|---|
| `1` / `2` / `3` / `4` / `0` | 現在地 / 地図 / GPS・記録 / ログ一覧 / 設定へ移動 |
| `Esc` | 現在地画面では画面選択MENU、それ以外のトップ画面では現在地へ戻る |
| `Del` | 戻る・取消。現在地画面では無効 |
| `Enter` | 選択中の項目を開く、または決定する |
| `G` | GPS・記録の操作ダイアログを開く |
| `S` | 画面を消す |
| `Tab` | 数字で選べる画面を順送りする |

数字キーはトップ画面と画面選択MENUで使えます。ログを開いた後の子画面では、`1` / `2` / `3`がログの文字 / 地図 / 統計表示に切り替わります。設定の子画面や確認ダイアログでは、トップ画面への数字ショートカットは使えません。

上下左右キーには、上`;`、下`.`、左`,`、右`/`も使用できます。確認ダイアログでは左右で項目を選び、`Enter`で決定します。`Esc`または`Del`は取り消します。画面下の枠付きEscと改行キー風の印は、利用できる操作を示します。無効な操作は暗い色で表示されます。

消灯中の最初のキーは画面の復帰だけに使われ、画面切替や設定変更には使われません。消灯してもGPS受信と進行中のログ記録は続きます。アラート音が鳴っている間は、最初のキーを消音に使います。

## 2. 現在地と区域地図

`1`の現在地画面には、地名、座標、速度、進行方位、高度、衛星数、記録状態、時刻、SDアクセス、電池残量を表示します。地名は選択中のマップセットとWordbookから取得します。GPSのFixを失うと地名と座標を消し、測位待ちを表示します。

`2`の地図画面には、現在地周辺の区域境界と現在位置を重ねて表示します。`＋`で拡大、`－`で縮小し、倍率は`1/4`、`1/2`、`1/1`から選べます。`=`キーも拡大として使えます。地図の更新中でも、GPSの現在位置と地名は別に更新されます。地図や地名が出ない場合は、Fixとデータセットの状態を確認してください。

ヘッダーのSDカードアイコンは、実際にカードへアクセスしている間に青く点灯します。ログ・地図・Wordbookの読書きを共通で示し、消えていてもSDカードが使えないことを意味しません。アラートが有効なときはベルを表示します。

## 3. GPSログを記録する

`3`でGPS・記録画面を開きます。GPSの測位状態、座標、速度、衛星数、記録時間、RAMバッファ使用数、SD保存済み件数などを確認できます。GPSの受信とログの記録は別の状態です。

この画面の`Enter`、または通常画面での`G`で操作ダイアログを開きます。左右で選択し、`Enter`で確定します。取消は`Esc`または`Del`です。

| 現在の記録状態 | 選べる操作 | 初期選択 |
|---|---|---|
| 停止 | 開始 | 開始 |
| 開始待ち・記録中 | 停止 / 一時停止 | 一時停止 |
| 一時停止中 | 停止 / 再開 | 再開 |

開始後は**新しく届く有効な測位点**から記録します。一時停止では新しい点の記録だけを止め、同じログファイルを維持します。再開すると同じファイルへ記録を続けます。停止では未保存分の書込みとファイル終了を進めます。保存・終了の処理中は完了表示を待ってください。記録を停止・一時停止してもGPS受信と現在位置の更新は続きます。

SDが使えない場合は新しい記録を開始できません。RAMで受け付けた点とSDへ保存済みの点は別で、書込み失敗や未保存分があれば画面に表示します。ログファイルは`/geoputer/logs/`へ保存します。

## 4. ログを閲覧・削除する

`4`でログ一覧を開きます。上下でファイルを選び、`Enter`でプロパティを表示します。一覧にはファイル名から`.gps.dat`を省いた名前と、選択ファイルの記録件数などを表示します。プロパティには基本情報が表示され、`Enter`で最初の測位点の文字表示へ進みます。

ログを開いた後は次の操作が使えます。

| キー | 動作 |
|---|---|
| `1` / `2` / `3` | 測位点の文字表示 / 地図表示 / 統計画面 |
| `Tab` | 利用できる表示を順送り |
| 左右 | 一時停止中は1点ずつ移動。再生中は逆方向 / 順方向を選択 |
| 上下 | 一時停止中は10点ずつ移動。再生中は速度を増減 |
| `B` / `E` | 最初 / 最後の点へ移動 |
| `P` | 地図画面で再生 / 一時停止 |
| `＋` / `－` | 地図の拡大 / 縮小 |
| `R` | 統計画面で再集計 |
| `Esc` / `Del` | 測位点表示からプロパティへ、プロパティから一覧へ戻る |

地図再生は、各測位点を順に表示します。全軌跡を線として残しません。地図表示には利用可能なマップセットが必要ですが、文字表示はマップセットがなくても使えます。統計画面で距離などの全件集計を実行します。読出し中や地図生成中は、完了まで待ってください。

一覧で`D`を押すと、選択ファイルの削除確認を開きます。初期選択は「取消」です。右へ移動して「削除」を選び、`Enter`で確定した場合だけ削除します。記録中のファイルは削除できません。

## 5. 設定を変更する

`0`で設定を開きます。設定トップの項目は「動作設定」「システム設定」「アラート」「データセット選択」「ストレージ操作」「バージョン情報」「ライセンス情報」です。

設定項目では、左右キーで値を直接変更できます。未変更の値は水色、変更中は黄色です。別の項目へ移ると変更を確定し、変更があった場合だけ保存します。黄色の状態で`Esc`または`Del`を押すと、その行の元の値へ戻します。確認ダイアログが出た操作は、左右で選び`Enter`で確定します。

### 動作設定

画面の表示言語、GPSログの記録間隔、SDへのまとめ書き間隔、画面消灯時間、明るさ、音量、省電力を設定します。「記録間隔」は測位点を採用する間隔、「SD保存間隔」はRAMに受け付けた点をカードへまとめて保存する間隔です。画面の日本語／Englishと地名に使うWordbookの`ja`／`en`は別設定です。

### データセット選択

「データセットを選択」で識別名を選び、必要なら「辞書／WORD」でWordbookを変更して「適用する」を選びます。「未選択」も選べます。記録中と一時停止中は、先にログを停止し、保存・終了の完了を待ちます。索引が欠けた場合は「キャッシュ再生成」、既存索引を確認したい場合は「キャッシュ検証」を使います。いずれも対象データセットを選んで実行します。

### アラート

アラートはデータセットごとに保存します。「通知」をONにし、「区域判定」で即時 / 標準 / 確定を選びます。即時は現在の1セル、標準は周囲9セルのうち7セル以上、確定は9セルすべてが新しい区域になったときに通知します。監視対象はそのデータセットで最も細かい区域です。

通知音を左右で変更すると、その候補音を鳴らして確認できます。音量は「動作設定」で変更します。通知時間と設定の再読込もアラート画面から行えます。SDまたはデータセットが使用できないときはアラートを使えません。

### システム設定・ストレージ操作

システム設定では、GPSロガー / USB / Wi-Fiの起動モードを選び、「保存して再起動」で切り替えます。モード変更前にログを停止し、未保存分の書込みが完了している必要があります。「初期化」は同じシステム設定の中にあります。

ストレージ操作ではカード情報、再マウント、安全な取り外し、FAT32フォーマットを扱います。**FAT32フォーマットはカード全体を消去します。** M5Launcherを含む既存ファイルが必要なら、先に退避してください。

## 6. エラーとメンテナンス

GPSのFixがない場合も設定と既存ログの閲覧は利用できます。SDが使えない場合、有効FixがあればGPS情報を表示できますが、ログ保存と地図・地名の読出しはできません。データセットだけが使えない場合は地名検索を止め、GPSと利用可能なSDでのログ記録は継続します。

保存済みデータセットのファイル・索引が欠けたり不正になったりした場合は、原因を表示してデータセット未選択として起動を続けます。ファイルの配置を直した後、設定から対象を選び直すか、索引の再生成・検証を行ってください。

起動時の読込み前に設定へ入りたい場合は、Escを押しながら端末を起動します。メンテナンス画面ではデータセットやSDを修復できます。メンテナンスの設定トップでEscを押すと、通常モードへ戻るための再起動確認を開きます。

## 7. USBとWi-Fiでファイルを扱う

両モードはGPSロガーと排他的です。切替前に記録を停止し、SD保存が終わるまで待ちます。設定の「システム設定」→「モード」でUSBまたはWi-Fiを選び、「保存して再起動」を実行します。

### USBマスストレージ

USBモードではPCからmicroSDカードのファイルを閲覧・コピーできます。PCでの保存が終わった後、端末の「ロガーへ戻る」またはEsc / Delで終了確認を開き、終了を確定するとGPSロガーへ再起動します。PC側でまだファイルを編集中なら、保存を完了してから終了してください。

USBモードの「ログを書き出す」では、ログを選びGPX・KML・CSVへ変換できます。結果は`/geoputer/export/`へ保存されます。PCにSDカードを公開中は、画面の案内に従ってPC側の操作を完了してから書き出しを進めてください。

### Wi-Fi管理

Wi-Fiモードでは端末が独立したアクセスポイントになります。最初に表示される接続用QRをスマートフォンで読み取り、接続します。左右キーで管理画面URL用QR、SSID・パスワードの文字情報へ切り替えられます。QRが使えない場合は文字情報を入力し、端末に示されたURLをブラウザーで開きます。

Web管理画面には「情報」「ファイル」「データセット」の3画面があります。現在の「データセット」画面は準備中で、ファイルの閲覧・単体アップロード・削除、ディレクトリの作成・削除、テキストの表示・編集は「ファイル」画面で行います。tgzのアップロード・自動展開には対応していません。Wi-Fiパスワードを変える場合は本体の`R`で再生成の確認を開きます。Esc / DelではWi-Fiモード終了の確認を開きます。

Wi-Fiでの単体ファイルアップロードは実装されていますが、実機で転送中にリセットした報告があり、安定動作の確認は完了していません。マップセットの初回導入には、カードをPCで直接編集する方法、またはUSBマスストレージモードを使用してください。
