# Geoputer マップセットの概要

[English](mapsets.en.md)

対象バージョン：v0.1.0

マップセットは、Geoputerが**座標から区域名を調べ、区域の境界を描くためのデータ**です。道路地図や衛星写真ではありません。GPSログの記録には不要ですが、現在地の地名表示、区域地図、区域アラート、ログの地図表示には利用可能なマップセットが必要です。

## マップセットの選び方

選ぶときは、次の4点を確認してください。

1. **対象地域**：現在地や、後で閲覧するログの地域を含むか。
2. **区域の種類と細かさ**：市区町村、町丁・字等、統計区など、知りたい単位に合うか。同じ国でも区域の種類が異なるセットがあります。
3. **データの時点**：識別名の年や配布ZIP内の説明を確認してください。区域の変更があった場所では、現在の行政区分と異なる場合があります。
4. **Wordbook言語**：そのセットに、表示したい地名の言語があるか。画面メニューの言語と、地名に使うWordbookの言語は別設定です。

マップセットZIPは[GitHub Release v0.1.0](https://github.com/nyatla/geoputer/releases/tag/v0.1.0)で配布します。各セットの主要仕様は[マップセット仕様一覧](mapsets-spec.md)で比較できます。

### 日本向けの例

| 識別名 | 表示する区域 | Wordbook |
|---|---|---|
| `jp-n03-y2026-1` | 都道府県・市区町村 | `ja`、`en` |
| `jp-est-y2020-2` | 町丁・字等と下位地区 | `ja`、`en` |
| `jp-esc-y2026-2` | 海岸線を反映した小地区等と行政区域 | `ja`、`en` |

市区町村を知りたい場合はN03、より細かな町丁・字等を見たい場合はe-Stat系が候補です。海岸線を反映した区域は、元データの区域・対象時点が異なるため、必要な用途に合わせて選んでください。細かいセットほど、すべての地点で住所の番地まで分かるわけではありません。

### 日本以外の例

たとえば米国には州、郡、郡内の下位区域をそれぞれ扱うセットがあり、オランダには自治体と地区・近隣区域のセットがあります。台湾の村里、英国の地方行政区、世界各地の行政区域を対象にしたセットもあります。同じ地域を複数のセットで扱う場合は、一覧の「内容」で区域の種類を比較してください。日本の3セット以外は`en`のWordbookを収録しています。


## 1つのZIPに入っているもの

各ZIPは1つのマップセットです。ZIP内のファイルはディレクトリを作らず、直下に収録されています。

| ファイル | 役割 |
|---|---|
| `dataset.ini` | タイトル、説明、地図とWordbookの対応、地名の表示書式 |
| `map.glc` | 区域コードを格納した地図データ |
| `*.giswordbook` | 区域コードに対応する地名。利用できる言語分を同梱 |
| `README.md`、`NOTICE-*.md` | 元データ、加工内容、出典と利用条件 |

日本の3セットには日本語と英語のWordbookが同居します。画面表示を英語に切り替えただけでは地名のWordbookは変わりません。端末のデータセット選択画面で、使用する`ja`または`en`を指定します。

SDカードでは、ZIP名と同じ識別名のフォルダへ展開して`/geoputer/dataset/<識別名>/`に置きます。端末は複数のセットを保存できますが、地名検索に使うセットは一度に1つです。選択時に検索用の索引を生成します。配置・適用の手順は[セットアップマニュアル](setup.md#4-マップセットを選ぶ)を参照してください。

## 表示結果の範囲

Geoputerは、GPS座標が選択中の区域データのどのセルに入るかを調べ、その区域名を表示します。最寄りの建物や道路から住所を推定する方式ではありません。区域の境界や細い地形の表現は、元データの形状とマップセットの格子解像度に依存します。境界付近ではGPS測位の誤差も表示結果に影響します。

各セットの元資料、収録範囲、利用条件はZIP内の`README.md`と`NOTICE-*.md`で確認してください。採用したGLCの解像度やチャンク数を調べる開発者向けの資料は[マップセット選定一覧](dev/mapsets-selection.tsv)にあります。
