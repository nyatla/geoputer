# データセット未選択状態の検証

検証日: 2026-10-22

## 対象と結果

データセット番号0と空のWordbook言語を未選択として扱う実装を検証した。設定未保存時・設定初期化後は未選択とし、保存済みの形式バージョン3の選択と、形式バージョン1・2の従来の移行規則は維持する。仕様は[データセットメタデータ仕様8.7節](../08_データセットメタデータ仕様.md#87-データセット未選択)に従う。

Linuxホストで警告をエラーとするビルド、UBSan、標準ライブラリのアサーションを有効にし、設定・UI・Bootと実データによる地名検索のテストに成功した。Cardputer向けのPlatformIOビルドにも成功した。本変更の実機書込み・実機操作試験は行っていない。

| 検証対象 | 確認した動作 |
|---|---|
| 初期値と永続化 | 未選択を有効な設定として保存・復元できる。番号0に言語が残るレコードはチェックサムが正しくても拒否する |
| 既存設定 | 選択済みの99・en-usを復元でき、保存失敗時に既存の保存値を保持する。旧形式は従来どおり01・既定言語へ移行する |
| 解除操作 | 取消が初期選択で、確認済み操作だけがClear要求を発行する。SD未挿入・メタデータ異常でも解除の確認を開ける |
| 操作の制約 | PAUSED・Storage処理中・すでに未選択の場合は解除を確定できない。確認中の状態変更で実行可能性を再判定する |
| 索引保守 | 未選択対象への再生成・検証の確定と要求発行を抑止する |
| Boot | GALUCHAT DATAのNONEを正常完了とし、未選択だけでは警告や待ち時間延長にならない |
| 地名とGPS | 未選択の日本語・英語表示、旧地名の消去、古い世代の検索結果の拒否を確認した。未選択でもGPS Loggerの開始要求を発行できる |
| 自動読込みの抑止 | PlaceLookupを未選択にし、prepare・有効Fix検索・無効Fix検索・closeを繰り返してもObserverのSDアクセス件数が増加せず、画像キャッシュを確保しない |
| 選択後の復帰 | 明示的なconfigureで読込みを再開でき、確定済みのデータセット異常も未選択へ戻せる |
| 実データ回帰 | N03のGLCとUTF-8 Wordbookで324点のキャッシュ／点取得比較、通常の地名検索、破損・欠落・文字コード未対応の扱いを確認した |

実行コマンドは`python3 tests/run_native.py`、N03の実ファイルを指定した`python3 tests/run_place_files.py`、`pio run -e cardputer-adv`である。UI・設定保存の試験はホスト用バックエンドで行い、App・StorageTaskを含む実機向け処理はファームウェアのビルドで整合性を確認した。実際のNVS・SDとGPSを同時利用した未選択時の連続記録は実機確認の対象として残る。
