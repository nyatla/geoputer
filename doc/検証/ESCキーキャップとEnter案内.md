# ESCキーキャップとEnter案内

実施日: 2026-10-29。現行仕様は[共通キー操作](../画面・操作/共通キー操作.md)に従う。

![原寸の12倍プレビュー](../画面・操作/key-icons-preview.png)

ESCは幅16×高さ8の枠内にESCを描いた1ビットビットマップに差し替えた。高さは他のキーと同じ8ピクセルとし、隣接するS/Gと枠で区別する。Enterには8×8の折れ曲がった左向き矢印を使う。拡大・補間・フォント描画は使わない。

Enterは選択・確定・再試行・戻るの操作がある画面でローカルグループの先頭に置く。一覧・GPS・ログプロパティ・値編集・ダイアログ・完了後のBoot等を対象とし、実行不能ならグレーにする。LIVE、通常地図、ログ測位点・統計、ライセンス、表示専用の設定行には追加しない。キー操作自体の割当は変更していない。

フッターはキーごとの幅で送り、ESCだけ16ピクセル、Enter等は8ピクセルとする。グローバル・数値・ローカルの並びとグループ間だけの空白を維持する。すべて画面内に収まり、ヒープや常設のUI状態は追加しない。

## 確認

- run_native.py成功。画面ごとのキー列、8/16ピクセルの幅、Enterの有無、空のプロパティ／読出し中の無効表示、起動完了時の案内、ライセンスでの非表示を確認した。環境上LeakSanitizerを利用できないためASAN_OPTIONS=detect_leaks=0で実行し、AddressSanitizer・UndefinedBehaviorSanitizerおよび専用の確保回数検査は維持した。
- run_status_icons.pyの375描画ケース成功。全画面群・日本語／英語・4/16ビット色でESCとEnterの原寸パターン、キー位置、色、区切りと残りの空白を確認した。
- LIVE、設定、MENU/GPS、ログ、データセット、起動エラー、通常地図の生成器が成功。通常地図はN03の実データで1/1・1/2・1/4を生成し、4/16ビット色の一致を確認した。既存の仕様画像も差し替えた。
- cardputer-advのPlatformIOビルド成功。静的RAMは253,972 Bで不変、Flashは1,237,085→1,237,977 B（+892 B）。ELFのDROMにESCの16 BとEnterの8 Bを確認した。

この段階では実機へ未書込み。その後、[ログ表示の数値ショートカット](ログ表示の数値ショートカット.md)と合わせて実機へ書き込み、通常起動を確認した。
