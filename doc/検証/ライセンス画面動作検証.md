# ライセンス画面動作検証

検証日: 2026-10-15  
対象: Cardputer ADV、ASCII 8×8・29文字×9行のライセンス表示

## 1. 再現操作の監視

ユーザーの再現操作中に、通常ファームのシリアル出力を再起動せず180秒取得した。278行のログでSettingsとLive Placeの遷移、GPS通知の継続を確認した。例外、assert、Watchdog、低電圧リセット、ヒープ破損、予期しない再起動は記録されていなかった。ユーザーの再操作でも停止は再現しなかった。

今回の確認から前回の停止原因は特定できない。

## 2. 共通の操作シナリオ

ホストと実機の双方でtests/license_scenarios.hを実行した。全3,507行について、表示先頭0〜3,498の全位置を下端まで進め、上端へ戻した。GPS受信状態とStorage状態の内容更新、古い表示データの到着を混ぜても閲覧位置を維持した。

上下端での追加操作、左右・Enter・F2の入力、20回の閉じる／再度開く操作、無操作期限によるSleep操作の生成、受付結果の反映、復帰キーによるWake、Live Place復帰後のF2を確認した。ライセンス閲覧から設定変更・SD操作が生成されないことも確認した。

消灯・復帰はUiModelへ時刻と受付結果を与えた状態遷移の検証である。実機描画テストは、全本文を重複しない9行の表示窓へ分けてLCDへ送り、最後に同じページを128回描画した。

## 3. 実機描画の計測結果

| 項目 | 結果 |
|---|---:|
| 描画回数 | 929フレーム |
| 平均描画時間 | 39,297μs（約39.3ms） |
| 最大描画時間 | 48,775μs（約48.8ms） |
| 128回の繰返し前の空きヒープ | 292,552バイト |
| 同じ繰返し後の空きヒープ | 292,552バイト |
| 起動以降の最小空きヒープ | 287,328バイト |
| 最大連続空きヒープ | 258,036バイト |
| テスト用loopTaskの最小スタック余裕 | 4,456バイト |

全ページの進行中も記録された空きヒープは292,552バイトで一定だった。PASSまで到達し、停止・例外・Watchdogは記録されなかった。描画単体はUIの10msループ周期より長く、現在の長押しスクロール間隔100msより短かった。

計測には本番のUiModel・UiRenderer・PixelFontを変更せず組み込んだ専用ファームを用いた。この専用ファームはApp・GPS・Storageタスクを起動せず、描画ごとに1ms待機する。同時タスク稼働時の観測は第1節の通常ファームの監視で行った。

python3 tests/run_native.pyが成功した。実機用はtests/hardware/license_renderのPlatformIOプロジェクトでビルドした。手順は同ディレクトリのREADME.mdに記載する。
