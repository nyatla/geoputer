# Wi-Fi Web 3画面と日英対応の検証

2026-10-30。[Wi-Fi管理モード仕様](../19_Wi-Fi管理モード仕様.md)1.3のWeb画面を実装し、ローカルブラウザーとESP32-S3ビルドで確認した。今回の作業では実機への接続、再起動、書込み、アップロード試験を行っていない。

## 変更

Webを「情報」「ファイル」「データセット」の3画面へ分け、初期表示を情報にした。装飾を罫線・文字・標準コントロール中心に整理し、PCではファイル一覧を横並び、スマートフォンでは縦並びにする。320px以上の幅で操作ボタン44px以上、本文16pxを維持する。編集の保存・閉じるを本文の上へ移した。

データセットは準備中の表示だけで、管理APIやダミー操作は設けていない。ファイル画面を初めて開いたときに一覧を取得し、画面切替だけでは一覧を再取得せずディレクトリとページを保持する。転送中は画面・言語の切替を無効にする。SD利用不能が判明した場合は取得済み一覧の操作も無効になる。

Webの言語は日本語と英語。保存がなければブラウザーの言語から決定し、選択をlocalStorageへ保存する。保存できないブラウザーでも画面内の切替は使える。接続案内と管理画面で選択を共有し、翻訳のための端末通信やNVS変更は行わない。ファイル名・本文・端末の診断詳細は原文を維持する。HTML・CSS・JavaScriptと翻訳はFlash内の定数であり、外部フレームワークや端末側の新しい作業バッファは追加していない。

## ブラウザー検証

Chromium／Playwrightで実際のWifiWeb.hとWifiPortal.hからHTMLを取り出し、APIだけを模擬して実行した。実機のHTTP・SD・電波通信を試験した結果とは区別する。

| 試験 | 結果 |
| --- | --- |
| 日本語／英語×320・390・768・1280px | 8構成すべて成功。情報、プレースホルダ、ファイル一覧、ページ送り、テキスト保存、未保存取消、フォルダー作成・移動、単体アップロード、上書き、削除確認と取消、確定削除、情報更新、GPS終了要求を確認 |
| 最小幅・編集操作 | 横はみ出しなし。保存ボタンが本文より上かつ画面内にあることを確認。日本語の長いファイル名を折返し表示 |
| 通信と排他 | 情報の初期表示はディレクトリを読まない。プレースホルダ・言語切替・取得済み画面の切替では新たなAPI要求を送らない。転送応答待ちの間は画面・言語切替を無効化 |
| SD状態の変化 | 情報更新でSD利用不能と判明した後、取得済み一覧の操作とアップロードが無効になる |
| 保存済み言語 | 未保存、不正値、保存済み英語の3構成で初期選択・切替・リロード後の保持を確認 |
| ブラウザー保存禁止・SDなし | en-US、fr-FR、ja-JPで例外を出さず、英語／日本語への選択と切替が利用可能 |
| 接続案内 | 日英×320・390pxの4構成でURL、言語切替、管理画面へのリンクと選択の引継ぎを確認 |

全18構成が成功し、試験中のpageerrorは発生していない。ブラウザー結果は[ログ](20261030_Wi-Fi_Web3画面と日英_ブラウザー.log)を参照する。スクリーンショットの値は模擬APIによる試験用データであり、実機の残容量などの計測結果ではない。

## ビルドとメモリ

ESP32-S3のPlatformIO cardputer-advでコンパイル・リンクが成功した。比較元は直前のメモリ計測用ファーム（SHA-256: `0733f372295fda38a7f23266cb68443ea53823eb8cc454b7b14256a8b455cdd0`）のビルド値。

| 項目 | 変更前 | 変更後 | 差 |
| --- | ---: | ---: | ---: |
| 固定RAM | 282,316 B | 282,316 B | +0 B |
| Flash | 1,793,269 B | 1,803,797 B | +10,528 B |

追加のWeb画面・翻訳はFlashへ収録される。固定RAMはリンカのデータ領域集計であり、Wi-Fi通信中のヒープピークやタスクのスタック最大深さの実測ではない。今回これらの実機測定は行っていない。ファイル転送・保存のバックエンド、モード別unionの配置、固定FILと4 KiB転送バッファは変更していない。

[ビルドログ](20261030_Wi-Fi_Web3画面と日英_ビルド.log)。ファームウェアSHA-256：`2c818c757e96a6b66e2dc1791dc67ace53831fd92cee0683d40dc9841a3af22f`。成果物は`.pio/build/cardputer-adv/firmware.bin`。ビルド時点では実機未更新。実機更新の結果は下記追記を参照する。


## 実機更新（2026-10-30追記）

利用者の実機更新依頼により、上記SHA-256と一致するバイナリをMAC `70:AF:09:DF:46:D0`のCardputer ADVへ書き込んだ。アプリ領域0x10000だけを更新し、NVS・SDは保持した。書込み後のハッシュ検証に成功し、通常起動へ戻した。

保存済みの起動モードはGPSであり、GPS FIX、時刻同期、LivePlaceの地名表示（DATASET READY）をログで確認した。この更新作業ではWi-Fiモードへの切替や実無線でのファイル操作を行っていない。

GPS起動後の単一スナップショットでは、空きヒープ43,288 B、起動以来の最小空き42,768 B、最大連続空き32,756 B、Appタスクの最小残スタック2,676 Bを得た。これはWi-Fi稼働時のヒープや全機能のピーク計測ではない。
