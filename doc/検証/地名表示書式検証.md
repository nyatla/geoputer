# 地名表示書式の実装と検証

2026-10-17。`dataset.ini`のWordbook言語セクションに`display_line1` / `display_line2`を追加した。`%0`〜`%9`を0始まりの項目、`%%`を文字の`%`として扱う。詳しい定義は[データセットメタデータ仕様5.1節](../08_データセットメタデータ仕様.md#51-地名2行の書式)を参照する。

## 実装

StorageがUTF-8を検証し、指定書式または従来の配置で完成した2行を作る。WordbookCacheとPlaceResultも最終2行を保持し、Appによる3階層からの再結合を廃止した。データセットのReader再オープン時に書式を読み直し、古い地名キャッシュを破棄する。

地名の半角スペースU+0020は8×16ドット・8ドット送りとし、その他の地名文字と全角スペースは従来の16ドット幅を維持した。幅計算と描画で同じ文字幅を使う。1行の上限232ドットは`application/Config.h`へ集約し、超過時はUTF-8の境界を保って48ドットの`...`を収める。`PlaceLineBuilder`は固定64バイトのバッファで展開し、巨大な連結文字列を確保しない。
