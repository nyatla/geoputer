# データセットメニューとキャッシュ保守の検証

検証日: 2026-10-22

## 変更した動作

データセットメニューを、データセットを選択・キャッシュ再生成・キャッシュ検証の3項目へ整理した。通常選択の先頭に未選択を置き、再生成・検証では別の対象一覧から番号を選んで確認する。保守対象の適用やNVS変更を行わず、使用中が未選択でも01〜99を指定して保守できる。画面と操作条件は[Settings仕様](../画面・操作/settings/README.md#データセットメニューとキャッシュ保守)、処理内容は[事前索引仕様11節](../11_データセット事前索引ファイル仕様.md#11-索引保守と全言語の利用)に従う。

事前に判明する記録状態・SD・Storage・NVSの条件とINIの構成不正は、該当操作をグレーアウトして理由を表示する。ファイル読取り・破損・索引不一致など試行が必要な問題は実行結果で示す。NVSが使用できない場合も、設定保存を伴わないキャッシュ保守は利用できる。

## ホスト検証

`python3 tests/run_native.py`、N03の実ファイルを指定した`python3 tests/run_place_files.py`、e-statの実ファイルを指定した`python3 tests/run_dataset_index.py`を実行し、成功した。警告をエラーとして扱い、UBSanと標準ライブラリのアサーションを有効にした。

| 検証対象 | 確認した内容 |
|---|---|
| 3項目の入口 | 末尾がキャッシュ検証となり、独立した解除・部分対象選択の入口がない |
| 未選択 | 通常一覧の先頭だけに仮想の番号0を置く。SD未挿入でも解除の確認を開け、既に未選択・記録中・NVS不可では要求を発行しない |
| 対象一覧 | 再生成・検証の用途を保持してページ移動し、番号0を含めない。地図・辞書・索引を開かずINIだけを読む |
| 対象と確認 | 使用中が未選択でも任意番号の確認へ進め、取消が初期選択となる。確定要求は用途・一覧世代・選択行を保持する |
| 既知の制約 | 記録中、SD不可、INI不正は確認を試す前に無効にする。開いた確認中に状態が変化した場合も再判定する |
| 進捗・結果 | 処理中の離脱・消灯を抑止し、結果から元の操作の対象一覧・メニューへ戻る |
| N03による回帰 | 仮想の未選択行、疎な番号のページ移動、一覧で既知のメタデータ異常、実地名取得と324点のキャッシュ／点取得比較 |
| 全言語再生成 | 複数言語を含む正式索引を生成でき、失敗時に旧ファイルを保持・復元する |
| 元データ突合 | CRCが正しくても地図位置・Wordbook枝位置が異なる索引を検出する。地図・辞書の再生成で修復し、再検証に成功する |
| 読取り専用 | 検証の成功・不一致結果で既存索引の内容を変更しない |

再生成は一時ファイルへの生成、構造・CRC検査、元データとの突合、同期・閉鎖、正式ファイルへの公開を行う。検証は元GLC・Wordbookから再計算した索引レコードとの照合であり、全圧縮本文・全地名の完全復号ではない。
