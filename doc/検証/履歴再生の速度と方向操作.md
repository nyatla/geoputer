# 履歴再生の速度と方向操作

実施日: 2026-10-29。操作仕様は[ログプロパティ・測位点・統計画面](../画面・操作/log-detail/README.md)を参照する。

## 変更

地図のPLAY中は上で加速、下で減速、左で逆再生、右で順再生を選ぶ。速度は1/4×・1/2×・1×・2×・4×、初期値は1×・順再生とする。速度・方向変更は現在点と処理中の読出しを保持し、再生を停止しない。既に要求した点は取得を完了してから新しい方向へ進む。ヘッダーにはPLAY/PAUSE、方向、速度、保存時刻を固定位置に表示する。

PAUSE中と文字表示の矢印は従来どおり1点／10点送りとする。Pで一時停止・再開しても速度・方向を維持し、別ファイルを開いた場合は初期値へ戻す。順再生の末尾・逆再生の先頭ではPAUSEになる。

速度は点・地名・地図の取得完了後に確保する最小表示時間であり、記録時刻に比例した再生速度ではない。読出しが遅い場合の追いつきや点の省略は行わない。
