# 設定の直接編集と変更時保存の検証

確認日：2026-10-30。

## 操作と結果

| 操作 | 結果 |
| --- | --- |
| 動作設定でEnterを押さず左右 | 選択行の候補値を直接変更し、変更中は黄色 |
| 左右で元の値へ戻す | 水色へ戻り、確定しても保存要求なし |
| 変更後に上下で別項目へ移動 | 移動前の項目を確定し、変更があった場合だけ保存要求を1回発行 |
| 一覧の端で移動できない上下キー | 項目を変えず、未確定の変更も維持 |
| 変更中のEscまたはDel | 元の値へ戻して同じ行に留まり、保存要求なし |
| 未変更時のEscまたはDel | 従来の親画面へ戻る |
| Enter | 変更中の値をその行で確定。未変更なら保存要求なし |
| Storage使用中に変更確定を試す | 未確定値を保持し、保存したことにして移動しない。取消は可能 |
| システム設定のモードを変更して移動 | UI内の候補として確定。保存・再起動は専用項目と確認を経て実施 |
| Wordbook言語を変更して移動 | 非同期の読出し結果を候補として確定。データセットの適用・保存は最終行の操作で実施 |
| アラート値を変更して移動 | SaveAlarm要求を発行。元へ戻した場合はファイルを再保存しない |

変更前の値はUI所有の固定メンバーへ保持し、候補値との比較で変更状態を判定する。設定操作ごとの動的確保、新しいキュー、画像バッファは追加していない。GPSなどの内容更新で未確定の候補値を上書きしない。メニューを開くEnter、実行操作のEnter、確認ダイアログ、ライセンスの左右ジャンプは維持する。

## ホスト確認

`ASAN_OPTIONS=detect_leaks=0 python3 tests/run_native.py` が成功した。日本語・英語の全動作設定、値の往復、Esc／Del取消、上下移動による確定、Storage使用中、システムモードの候補確定、Wordbook言語の非同期変更と取消、アラートの保存抑止、キーガイドを確認した。既存のGPS・ログ・USB・INI・音声／省電力の回帰テストも成功した。

この実行環境では変更前のキーボード試験でもLeakSanitizerが実行環境制約で終了するため、リーク検出だけを無効化した。AddressSanitizerおよびUndefinedBehaviorSanitizerは各既存ランナーの指定に従って有効である。リーク検出の成功を示す結果ではない。

`tools/render_settings_layout.py` の本番UiModel・UiRendererを用い、出力先を一時領域にした確認で日本語24種・英語24種が成功した。変更中の言語は黄色、通常値は水色、左右寄せと画面端、既存のライセンス本文が不変であることを確認した。確認した画像をSettings文書へ反映した。

`PLATFORMIO_CORE_DIR=/tmp/geoputer-pio-core /tmp/geoputer-pio-venv/bin/pio run` が成功した。比較元は[省電力レベルとオーディオ待機停止の検証](省電力レベルとオーディオ待機停止の検証.md)に記録された変更前のビルドである。
