# 地図・ログ再生のキー割当変更

検証日: 2026-10-25（JST）。対象: Cardputer ADV / ReverseGeoputer。

## 操作

通常地図とログ地図を共通化し、＋で拡大（1/4→1/2→1/1）、－で縮小（1/1→1/2→1/4）する。端では停止し、循環しない。Cardputerの物理=キーはShiftなしでも拡大として受け付ける。ShiftやFnを付け外ししても、同じ物理キーを新しい押下として扱わない。

ログ地図の再生・一時停止はPとする。旧Zの倍率循環とSpaceの再生切替は廃止する。ログの左右は1点送り、上下は10点送りを維持し、通常地図では上下左右に倍率変更を割り当てない。画面ガイドは通常地図に＋・－、ログ地図に＋・－とPを表示し、倍率端の無効キーはグレーにする。

## 検証結果

- `tests/run_native.py`を通過。物理＋・=・－・PとFn有無、旧キーの廃止、倍率端、処理中の操作保持、全方向キーと倍率変更の分離、消灯中の復帰専用動作を確認した。既存のGPS・設定・記録・USB・フォント等の検証も通過した。
- `tests/run_logger_app.py`を通過。実際のApp・UIを接続し、ログ地図の＋・－で点番号が変わらないこと、Pの再生再開、手動移動・ダイアログ・消灯による停止、閲覧中の記録継続を確認した。
- `tools/render_log_browser.py`の日本語・英語各28場面を通過。
- `tools/render_map_view.py`をestat実データの3倍率・各8状態で実行し、24場面を通過。＋・－の8×8字形全体と有効・無効色を検査し、パレットとRGB565の全画素一致を確認した。旧矢印の画素座標を前提とする検査は新キーの字形検査へ変更した。
