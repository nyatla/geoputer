# ログ表示の数値ショートカット

実施日: 2026-10-29。仕様は[共通キー操作](../画面・操作/共通キー操作.md)と[ログ閲覧](../画面・操作/log-detail/README.md)を参照する。

プロパティ・文字・地図・統計の各画面では、1＝文字、2＝地図、3＝統計に直接切り替える。フッターの数値グループも123へ切り替え、現在の表示先はシアンとする。プロパティには対応する現在番号を設けない。読出し・集計中、データセットなしの地図、空ファイルの測位点などはグレーにして実行を受け付けない。0/4はログ下位画面では使わず、トップ画面や他の下位階層の割当は維持する。

Mキーと表示選択ダイアログの実装・描画・旧画像を削除した。Vの文字／地図切替、Pの再生、Rの再集計、Esc/Delの階層戻りは維持する。文字／地図間では画面世代・現在点・レコードキャッシュを維持し、表示種類が変わる場合だけPLAYを一時停止する。同じ表示先の数字は何も変更しない。統計からの復帰も現在点を保持し、集計済み結果は同じファイル内で再利用する。

## 確認

- run_native.py成功。各子画面からの3表示への直接選択、0/4の無効、ダイアログ優先、データセットなし・読出し中の無効表示、フッターの順序と表示幅、設定下位画面の数値無効を確認した。環境で利用できないLeakSanitizerのみ無効にし、AddressSanitizer・UndefinedBehaviorSanitizerと確保回数検査は維持した。
- run_logger_app.py成功。実際のUI→App経路で1/2/3の切替、文字／地図間の画面世代と点の維持、PLAY中の現在表示再選択、表示変更による一時停止、統計から同じ点への復帰、集計結果の再利用を確認した。
- run_status_icons.pyの375描画ケース成功。数値グループ、選択色、無効色、枠付きESCとEnter、SD/電池ヘッダーを日本語／英語・4/16ビット色で確認した。
- render_log_browser.pyの各言語34シーンが成功し、現行画像を更新した。Mダイアログの旧画像は削除した。
- cardputer-advのビルド成功。静的RAMは253,972 Bで不変。Flashは直前のESC/Enter版1,237,977 Bから1,237,769 Bへ208 B減少した。新たなヒープ領域や常設の画面データは追加していない。

## 実機

枠付きESC・Enter案内も含めてMAC 70:AF:09:DF:46:D0のCardputer ADVへ書き込んだ。アプリ領域のみを更新し、ハッシュ照合と通常起動を確認した。物理キーを押してのログ表示切替は今回の自動確認には含めていない。
