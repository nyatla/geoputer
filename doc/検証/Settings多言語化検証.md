# Settings多言語化検証

検証日: 2026-10-16  
対象: Settings、SettingsStore、UiModel、SettingsText、PixelFont、UiRenderer  

## 1. 実装

動作設定の先頭に表示言語を追加し、日本語 / Englishを選択できるようにした。4行の表示範囲で全7項目をスクロールする。初期値は日本語、Enterで確定後にAppが適用した設定をUIへ返した時点で、同じ画面・選択位置へ反映する。候補編集中は現在の言語を維持し、Esc / Delで取り消せる。言語は通常のSaveSettingsでNVSへ保存し、次回起動時に復元する。

日本語の主表示は東雲16×16、英語はM5GFXのAsciiFont8x16を使用する。言語名の日本語は16×16、Englishは8×16で描画する。メニュー項目・値・確認文・カード情報・短い処理通知の翻訳をSettingsTextへ集約した。タイトル・キーガイドは従来のASCII 8×8、ライセンスは本文・配置・フォント・スクロール方式を維持する。

## 2. 設定・通信の検証

`python3 tests/run_native.py`は-Wall / -Wextra / -WerrorとUndefinedBehaviorSanitizer付きで成功した。

- 言語を含む全設定候補の符号化・復号が一致した。
- 旧バージョン1の実形式を持つ固定バイト列から、記録・保存間隔、消灯時間、輝度、データセット、GPS接続の6項目を引き継ぎ、言語を日本語にできた。
- NVSのホストAdapterで旧形式を読み、Englishを選択して保存した後、新しいSettingsStoreで再読込みして全設定を復元できた。
- 不正な言語、予約領域、未対応バージョンを、検査値が正しくても拒否した。不正データで呼出し元の設定を変更しなかった。
- 言語の候補変更と取消では現在の言語を変更せず、確定時にSaveSettings用のコピーを保持した。Appの適用通知を模したUpdateUiContentで、同じ画面・選択位置のままEnglishを適用できた。
- 7項目すべてを選択でき、末尾のデータセット・GPS接続は引き続き読取専用となった。
- 日本語の単位・保存通知と英語の単位・通知を確認し、メニュー・確認文の日本語字形が東雲に存在することを確認した。
- 既存のキー操作、GPS、ログ保存・復旧、ライセンスの全行閲覧試験も成功した。

NVSの名前空間・キーと16バイトのサイズを維持し、保存時の形式だけバージョン2へ更新する。旧6項目はオフセット4〜9、言語は10とする。読込みだけでは旧形式を書き換えず、次の確定・保存で移行する。詳細は[SettingsのNVS仕様](../画面・操作/settings/README.md#7-nvsの形式と旧設定の引継ぎ)に従う。

## 3. 描画・ライセンスの検証

`python3 tools/render_settings_layout.py --license-baseline .pio/license-multilang-before.bin`は成功した。実装のUiRenderer / PixelFont / UiModel / SettingsTextと、導入済みM5GFXのC64・ASCII 8×16の字形を使用した。

日本語・英語で各10状態（入口、動作設定先頭・末尾、言語編集中、ストレージ、カード情報、初期化、初期化確認、フォーマット確認、ライセンス）を描画した。項目と全候補値の横幅が設定値領域・画面外へはみ出さないこと、英語8×16と東雲16×16の字形、罫線を検証した。全20状態を240×135 pxと最近傍4倍の画像へ出力した。

変更前にライセンスの先頭・途中・末尾を実装からRGB565で保存した。変更後の日本語・英語の両方で、同じ3画面が変更前の194,400バイトと完全に一致した。変更前データのSHA-256は`eb05651d559fe86c81030487b729799beaa338a9c070775912af7814a4afc6cf`。ライセンス本文、折返し、位置、8ドット字形に差がないことを確認した。

`python3 tools/render_live_place_layout.py`も従来の20状態で成功した。Settings以外の地名・数値の字体と操作ガイドを維持している。旧Settings参考画像2枚は現在の画像へ置き換え、互換生成コマンドからも再生成しない。

## 5. 実機確認の扱い

2026年10月16日、COM6のCardputer ADV（MAC `70:af:09:df:46:d0`）を照合し、上記の通常ファームウェアをアプリ領域`0x10000`へ書き込んだ。esptoolの書込み後ハッシュ照合は成功した。NVS・SDカードは消去していない。

再起動後のUSBログで、240×135のUI、4タスク・5キュー、`NVS SETTINGS: LOADED`、FAT32、GPS UART、Galuchatデータのオープン、LivePlaceへの遷移を確認した。GPSはFIXとなり、習志野市の地名取得と、矩形・WordBook両キャッシュの初回MISSからHITへの遷移も確認した。起動ログは`.pio/languages-boot.log`へ保存した。

実キーによる言語切替、言語の実機NVS保存・再起動後の復元は未確認である。起動時の保存済み設定読込み成功と、ホストでの旧形式引継ぎ・保存試験を、これらの実機通し確認とは扱わない。今回の比較画像は実装のホスト描画であり、端末の撮影画像ではない。
