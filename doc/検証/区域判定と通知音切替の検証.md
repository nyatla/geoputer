# 区域判定と通知音切替の検証

2026-10-30。[区域アラート機能設計](../15_区域アラート機能設計.md)をセル単位の即時・標準・確定へ統合し、通知音変更時の音確認を実装した。今回はホスト検証と実機向けビルドまでとし、実機書込み・移動による越境・実スピーカーの発音試験は行っていない。

## 変更

設定は通知、監視階層、区域判定、通知音、通知時間、再読込の6項目。区域判定は即時／標準／確定（Immediate／Standard／Confirmed）とする。即時は中心1セル、標準は中心と隣接8セル中7票以上、確定は9票すべてが中心の新しい区域に一致した時に通知する。階層の親子ID列で区域を比較し、セル移動自体は通知しない。条件を満たすまで直前の確定区域を保持し、時間による再武装は行わない。

整数セルの隣接参照をCachedMapReaderへ追加し、距離m・緯度補正・同じセルへの再丸めをなくした。日付変更線の折返しと極点外の無効扱いを実装した。取得不能点は一致票に加えず、必要な票数は下げない。既存の固定コードキャッシュとUI借用領域を使い、新しい画像・キュー・動的確保は追加していない。Galuchat本体・SDKは変更していない。

独立した試聴項目を削除し、通知音の左右変更時に候補音を1パターン再生する。OFFでも再生し、画面を開いた時・行選択・確定だけでは再生しない。切替ごとの再生とSD保存は分離し、変更した値の確定時だけ保存する。音確認中は設定操作を継続でき、実際の越境通知では従来の最初のキーによる消音を維持する。

設定ファイルは64バイトを維持して形式2へ更新した。形式1は旧3モードを同じ並びの即時・標準・確定へ移し、通知ON/OFF・階層・音・時間を保持して保存し直す。旧判定幅は値域検査後に破棄し、新形式ではそのバイトを予約ゼロにする。破損時のOFF復旧と保存失敗時の利用不能化を維持した。
