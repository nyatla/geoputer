# Geoputer ドキュメント

利用者向けの資料は次の3つです。

- [セットアップマニュアル](setup.md)：対応機器、ファームウェア、microSDカード、マップセットの導入と初回確認
- [操作マニュアル](user-manual.md)：画面切替、GPS記録、ログ閲覧、設定、USB・Wi-Fi管理
- [マップセットの概要](mapsets.md)（[English](mapsets.en.md)）：選び方と収録内容。全件の比較表は[マップセット仕様一覧](mapsets-spec.md)

まず端末を使い始める場合はセットアップマニュアルからお読みください。画面の操作やエラーからの復旧には操作マニュアルを使用します。

設計、ファイル形式、実装、検証記録は[開発者向けドキュメント](dev/README.md)にあります。
