# アプリ別タスクと固定領域の検証

2026-10-30。基準コミットはe3afb88。GPS・USB・Wi-Fiを独立したアプリへ分離し、アプリ全体を最上位unionへ配置した。以下の容量はESP32-S3向けELFから取得し、ホストの64 bit sizeof値とは区別する。実機への書込み後、保存済みのWi-Fiモードでの通常起動を確認した。GPS・USBへの切替と各機能の実機操作試験は今回未実施である。

## 固定RAM

| 項目 | 変更前 | 変更後 | 差 |
| --- | ---: | ---: | ---: |
| アプリ全体の固定予約（外側管理含む） | 219,528 B | 216,832 B | −2,696 B |
| .dram0.data＋.dram0.bss | 281,908 B | 279,220 B | −2,688 B |

旧部分union単体との比較ではない。新しいApplicationRuntimeは選択タグ等を含めて216,832 Bであり、外側に旧UI・キューや旧Applicationを残していない。GPSのスナップショットからUSB・Wi-Fi用payloadを除去し、GPS側の管理も整理したため、最大予約はわずかに減った。既存の64 KiB区域キャッシュ、96 KiB地図／索引作業領域、UIの地図2枚はGPSアプリ内に維持する。

| 型 | 固定容量 |
| --- | ---: |
| GpsApplication | 216,824 B |
| UsbApplication | 24,880 B |
| WifiApplication | 25,080 B |
| ApplicationRuntime（タグ等含む） | 216,832 B |
| GpsUiTask | 32,104 B |
| GpsStorageTask | 174,328 B |
| GpsTask | 856 B |
| UsbUiTask | 17,692 B |
| UsbStorageTask | 2,864 B |
| WifiUiTask | 17,124 B |
| WifiStorageTask | 6,392 B |

各タスクの数値は、そのタスクの受信キューと固定状態を含む。Appの通知・同期結果キューはApp側に置き、タスク表へ重複加算しない。USBとWi-FiにはGPSの地図2枚・区域画像・記録リング・アラートを持たせない。

物理的な最上位予約は最大のGPSサイズに合わせて残る。USB・Wi-Fiの小さい型へGPS用資源を含めることと、union全体に余白が残ることは異なる。Wi-Fiでは、全タスクと通信を含むWifiApplicationの末尾からのみ、安全な余白をヒープ登録する。登録後の別アプリ構築は禁止する。USBの余白登録は追加していない。

App処理はloopTaskのまま。アプリが作るサブタスクのスタック指定は従来同様、GPSはUI 8 KiB＋Storage 12 KiB＋GPS 4 KiB、USB・Wi-FiはUI 8 KiB＋Storage 12 KiBとする。タスク制御領域、loopTask、SDKの無線・USB等のタスクと内部ヒープは別枠である。今回は実行中ヒープが何バイト増減したとの推定を実測値として記載しない。

作業用コピーの検収ビルドはFlash 1,810,101 B（基準より6,320 B増）。SDKは元のPlatformIO構成と同じM5GFX 0.2.33等を使用した。コピー上のGitビルド情報はunknownのため、リポジトリ上の最終ビルドでは埋込み情報による差が生じる。検収バイナリSHA-256は`fadcb827cea5a2f83611fd150bbd625df072fe684d2aae4f73dd9bc8975dccff`。

リポジトリへ反映後、通常のplatformio.iniで再ビルドを実施した。結果はSUCCESS（483.92秒）。固定RAMは279,220 B、ApplicationRuntimeと各アプリの型サイズも上表と一致した。最終Flashは1,810,065 B（基準より6,284 B増）。組込みGit情報はe3afb88d+dirty、ビルド時刻は2026-10-30 21:17:32 JST。生成したfirmware.binのSHA-256は`d5f03bf736b70761c21c306b3100a557cb2b44030cfbdcffa41100ac54ec82f8`。

## 実機書込みと起動確認

2026-10-30。MAC 70:AF:09:DF:46:D0を照合し、上記の最終バイナリを0x10000のアプリ領域へ書き込んだ。esptoolのデータハッシュ照合に成功。NVS・パーティション定義・SDカードは変更していない。

通常再起動後は保存済みのWi-Fiモードを維持し、`startup=OK phase=READY`を確認した。35秒のシリアル取得中、パニック・再起動ループは検出していない。`MODE-MEM`の各型サイズもELFと一致した。

起動後の一時点では空きヒープ191,156 B、起動以来の最小空き189,636 B、最大連続領域114,676 B。Wi-Fi Storageの起動ログでは開始前248,880 B、READY時191,164 Bである。測定時点が異なるため、これらを同一瞬間の値として扱わない。変更前との実機比較、Webでのファイル操作、GPS・USBモードの操作確認は別途行う。

書込み・起動ログは`.pio/appsplit-flash.log`、`.pio/appsplit-boot.log`に保存した。
