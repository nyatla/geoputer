# Escによる即時メンテナンス起動検証

実施日: 2026-10-23

## 変更

メンテナンスの入口をF1から物理バッククォートのEscへ変更した。Fnなし・ありのどちらでも同じ操作とし、Delは通常の戻る・取消に限定する。Bootの確認中・完了後と、記録停止・保存完了状態のLive Placeの異常から入れる。F1は未割当とした。

GPSロガー起動では、UIが最初のApp要求を処理する前にキーボードを走査する。Escが押されていれば保持し、Appが最初のUI内容を取得して、SD初期化より前にメンテナンスを表示する。設定復元完了や通常の1500ms受付期間を待たない。GPS・地図の自動初期化を抑止し、Storageの初期化とNVS設定復元だけを継続する。復元中は保存・媒体操作を受け付けず、復元後に保存済み設定を反映する。同じ押下の保持で終了確認を開かず、EscとDelの同時押下による二重取消も防ぐ。USB起動の既存動作は維持する。

## 実機書込みと通常起動

MAC `70:af:09:df:46:d0`とバイナリSHA-256を照合し、アプリ領域0x10000へ書き込んだ。esptoolのハッシュ検証が成功した。NVSとSDは消去していない。通常起動ログで、NVS設定復元、SDのFAT32マウント、GPS UART、データセット01（172チャンク）、Boot Ready、LivePlaceへの遷移を確認した。GPS FIXと「千葉県 習志野市」の地名取得も成功した。取得範囲にパニック・Watchdogエラーはない。ログは`.pio/esc-maintenance/flash.log`と`boot.log`へ保存した。Escを押しながらの電源投入は、物理キー操作を伴うため未確認として区別する。
