# ESC白色とPOINT地名16×16

実施日: 2026-10-29。

ESCはすべての画面・確認ダイアログで白に統一し、利用不能時のグレーを維持する。現在画面の数値のシアンは維持する。画像・操作仕様とROMパターンのプレビューも同じ配色に更新した。

POINTの文字画面では地名2行を東雲16×16に統一し、1行目y=84・2行目y=100に配置する。HDOPのy=75〜82、フッターの区切りy=118と重ならない。データセット未選択等の理由表示とNO REGIONも同じ文字サイズに揃える。地図上の地名は1行目8×8・2行目16×16のままとする。タイトルや補助値のフォントは変更しない。

## 確認

- run_status_icons.py成功。375ケースでESCの非強調色と実画素、フッター・SD/電池表示を確認し、8ケースで検索待ちの地名が消えないことも再確認した。日本語／英語・4/16ビット色を対象とする。
- render_log_browser.pyの各言語34シーンが成功。POINTの地名先頭「千」の原寸16×16パターンとy=84の配置を照合し、画面端・フッターとの重なりがないことを確認した。
- LIVE、設定、データセット、MENU/GPS、起動エラー、通常地図の生成器も成功し、白いESCで全画面群の画像を差し替えた。通常地図はN03実データの1/1・1/2・1/4で確認した。
- cardputer-advビルド成功、変更範囲のgit diff --checkに問題なし。静的RAMは253,972 B（変更なし）。Flash使用量は1,238,017 B。画像バッファやヒープ領域は追加していない。
