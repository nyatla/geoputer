# 画面専用UIデータの共用検証

確認日: 2026-10-25。比較元は`92e0516`。画面専用の表示データを共用し、タスク数・キュー数・通知と同期要求の契約・保存形式を維持した。

後続の作業領域・画面群の整理は[画面群リソース整理の検証](画面群リソース整理の検証.md)へ記録した。本書の数値と調査判断は表示データ共用の時点を示す。

## 変更内容

UiDataのLogBrowserViewとDatasetViewを種別付きunionへまとめた。読取り専用のbrowse() / datasets()は保持中の種別だけを参照し、別種別ではFlash上の空データを返す。editBrowse() / editDatasets()は書込み先を明示し、種別が変わる時だけ配置newでその領域を初期化する。追加のヒープ確保は行わない。App・UI・UIQueueは独立した値コピーを保持し、UiDataがtrivially copyableであることを静的に確認する。

ログ一覧・詳細・測位点とUSBエクスポートのファイル一覧は同じLogBrowserViewを使う。ログ内の階層移動では一覧名と選択位置を維持する。データセット要求の完了はtokenと保持種別を照合し、別種別へ移った場合は待機tokenを解消して結果を破棄する。同期SetUiScreenの結果待ち中に通知が届く場合も対象とする。ログ結果は既存の取消・画面世代・token照合で破棄する。

## メモリ

ESP32-S3向けコンパイラのsizeofをオブジェクトのシンボルサイズから確認した。ホスト環境のポインタ幅による推測値ではない。

| 対象 | 変更前 | 変更後 | 削減量 |
|---|---:|---:|---:|
| UiData | 1,696 B | 1,248 B | 448 B |
| UiRequest | 1,728 B | 1,280 B | 448 B |
| UiModel | 2,088 B | 1,640 B | 448 B |
| 通常ファームの静的RAM | 69,096 B | 67,752 B | 1,344 B |

AppのUiData、UiModel内のUiData、容量1のUIQueueの合計で1,344 B減った。通知816 B・戻り値576 B・Storage要求144 Bのサイズは変わらない。UI要求を置くローカル変数も448 B小さくなるが、動的ヒープや実機スタックの最大使用量の再計測は行っていない。通常ビルドのFlash使用量は1,213,389 Bから1,214,685 Bへ1,296 B増えた。
