# メインレイアウト1.2検証

本書は1.2の検証記録。最新の実装・画像は[メインレイアウト1.3検証](メインレイアウト1.3検証.md)を参照する。

検証日: 2026-10-15  
対象: Cardputer ADV、Live Place採用仕様1.2  

## 実装

AppがStorageの3階層の地名結果を2行の住所へ整形し、UIへの値コピーとして保持する。1行目は都道府県と市区町村、2行目は取得済みの下位住所とし、N03では2行目を空欄にする。UTF-8の境界を保って各行14セルまでに省略する。再検索中は前の住所と検索Fixを保持し、結果確定時に一緒に差し替える。

UiRendererは240×135 pxで住所2行、左のSPD / HDG、右のLAT / LON / ALT / SATを描画する。住所・速度・方位は東雲16ドット、ラベル・単位・補助情報はC64 ASCII 8ドットで、整数座標・アンチエイリアスなしとする。速度の桁増加時はkm/hを上段へ移し、HDGは真北基準のGPS進行方位として整数度へ丸める。ALTはGGAの海抜高度である。HDOPは表示だけから外し、GPS通知と測位レコードには保持する。

RG / SD、電池、時計、ログ操作の意味を維持し、赤帯はy=107〜119の記録詳細行へ移した。変更はAppの住所整形とUIの表示に限定し、SDのログ形式とGPSの解析・受信処理は変更しない。

## ホスト検証

`python3 tests/run_native.py`は-Wall / -Wextra / -WerrorとUndefinedBehaviorSanitizer付きで成功した。既存の同期通信、設定、GPS、ログ保存・復旧、ライセンス閲覧に加え、次を確認した。

- 3階層から2行への整形、N03での空欄、欠けた行政階層、長い住所のUTF-8省略、入力結果の保持。
- 速度4.2 / 14.2 / 999.9と表示範囲超過、桁数に応じた単位位置の選択。
- 方位の度記号、359.6°から0°への丸め、負の海抜高度、経度-180.000000。
- 有効な0と未取得の区別、非有限値・無効な方位の排除、Fix喪失時の全GPS表示の無効化。
- 表示住所に対応するFixの緯度・経度を使い、速度・方位等は最新GPSの項目別有効性に従う。

## 描画・画像

`python3 tools/render_live_place_layout.py`で実装のUiRenderer / UiModel / PixelFont / Shinonomeを無改変でホスト実行した。通常記録、一時停止、SD保存失敗、GPS受信断、再構築、N03、ログ書込み、読出し、辞書読出し、未準備の10状態を生成した。文書用は240×135 pxの10枚と最近傍4倍の10枚とし、同名の旧レイアウトを置換した。

さらに長い速度、電池100%、経度・高度の端値、未取得、方位の周回、速度範囲超過、有効な0、長い住所の8状態を一時ディレクトリで描画した。全18状態で白い区切り線と縦線が文字に上書きされないこと、右端4ドットの余白、度記号の東雲16ドットとの画素一致、N03の空の2行目、電池100%のC64字形との画素一致を検証した。RG / SDの色とエラー帯の位置も画素値で確認した。

画像は例示入力から生成したもので、実機の測位値や画面キャプチャとして扱わない。

## ビルド・実機

`PLATFORMIO_CORE_DIR=/tmp/geoputer-pio-core /tmp/geoputer-pio-venv/bin/pio run -e cardputer-adv -j 4`でビルドに成功した。ビルドログに警告・エラーはなく、静的RAMは42,296 / 327,680バイト、Flashは1,051,253 / 3,342,336バイト。住所の表示用コピーを3行から2行へ変更したため、従来ビルドより静的RAMが1,152バイト減った。

COM6のMACが既知のCardputerと一致することを照合して、通常ファームのアプリ領域0x10000を書き込み、esptoolのハッシュ検証が成功した。NVSとSDのフォーマットは行わない。ファームSHA-256は`7f6c82abfd48aa313055520f901dca94652aaea9fcc8ad3dd34c248dc577ed96`。

通常起動後30秒のUSBログで、6項目のBootチェック成功、Live Placeへの遷移、有効GPS FixとJST時計を確認した。実データセットで「千葉県 習志野市」が1行目、下位住所が未取得の2行目は空欄となる結果を確認した。64KiBキャッシュのMISS後にHITへ移行し、例外・アサート・再起動は検出しなかった。キャッシュ確保後の空きヒープは147,096〜147,296バイト、Storageの残スタック観測値は7,444バイトだった。

実機のLCDを撮影して画素比較した結果ではない。レイアウトの画素検証は上記の実装コードを用いたホスト描画、実機は起動・GPS・地名検索のログ確認とする。
