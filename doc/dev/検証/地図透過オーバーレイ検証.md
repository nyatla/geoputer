# 地図透過オーバーレイの検証

実施日: 2026-10-25

## 対象

地図領域240×101画素を維持し、地名背景の黒帯を撤去した。左上に1/1・1/2・1/4、その隣に距離値と目盛り、右端に北方位を配置する。地名はx=4、1行目y=88の8×8、2行目y=100の16×16とし、字形の周囲だけ黒く縁取る。エラーはy=48に透過描画する。現在地カーソルは文字より手前に描画する。

## ホスト画像検証

`tools/render_map_view.py`で実際のe-stat地図・Wordbookを読み、3倍率それぞれのready / updating / reading / no-fix / read-error / cursor-near / cursor-edge / cursor-lostの24シーンを検証した。全シーンで4bitパレットとRGB565の描画結果が一致した。

倍率の字形、8×8・16×16の地名字形、カーソル位置・色、更新中の完成画像維持を検査した。文字と1ドットの縁取り以外では元の境界画素が保たれることも比較し、従来の地名帯・右側の距離表示が地図を隠さないことを確認した。日本語8×8のプレビューは、実機と同じM5GFXのlgfxJapanGothic_8データを展開して作成した。
