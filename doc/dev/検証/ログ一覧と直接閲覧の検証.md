# ログ一覧と直接閲覧の検証

実施日: 2026-10-26。比較元はSD→電池→残量率の共通ヘッダーを実機へ反映した版。

## 表示と遷移

LOGSでは末尾の.gps.datだけを表示名から取り除き、残った名前が26文字を超えた場合に省略する。Storage・App・削除確認は完全な名前を保持し、拡張子を省いた名前でファイルを開かない。

下段左にページ番号/総ページ数、右に選択ファイルの件数とPTSを表示する。件数は一覧で取得するstatのサイズから(サイズ−512)/32を切り捨てて計算し、512バイト未満は0とする。ヘッダー・レコード・CRCは読まない。FAT32でsigned 32-bit off_tとして返される2GB超のサイズもビットを保持して扱う。

既存の一覧走査のstatを再利用し、候補6件の件数、全ファイル数、先頭順位を返す。選択移動だけではSDアクセスを増やさない。件数は一覧取得時点の保存済みスロット数であり、現在記録中の追記は一覧を取得し直すまで反映しない。内容が壊れていてもサイズ由来の値を表示するため、有効な測位点数の検証結果ではない。

一覧のEnterで文字表示を直接開き、保存済み範囲の確認後に最初の最大10件を自動取得する。Vで地図/文字、Pで地図再生/一時停止、Esc/Delで元の一覧・選択行へ戻る。中間のLogDetail画面ID、表示メニューとその操作コマンドを削除した。空の正常ログはNO POINTS、形式不正はエラーを表示し、読出し待ちのままにしない。ログを実際に開くときの内容検証と、その後のレコード検証は維持する。

SDアイコンは12×12のまま、斜めの角、輪郭、端子、内部の3×5ドットのSD字形を持たせた。非アクセス時は黒地・暗灰の輪郭と字形、アクセス中は青い本体と白い輪郭・字形で示す。本体と輪郭の2面を計48バイトの定数としてFlashへ格納し、動的確保は行わない。

## メモリ

ESP32-S3のコンパイラによるsizeofと通常ビルドの値を比較した。

| 対象 | 変更前 | 変更後 |
|---|---:|---:|
| LogFileList | 名前だけ288 B | 名前・件数・総数・順位で320 B |
| LogReadReply | 504 B | 504 B |
| AppNotification | 816 B | 816 B |
| LogBrowserView | 464 B | 488 B |
| UiData | 1,256 B | 1,272 B |
| UiRequest | 1,288 B | 1,304 B |
| 常駐RAM | 95,016 B | 95,064 B |
| Flash使用量 | 1,229,369 B | 1,228,665 B |

LogFileListは、名前6×48 B、件数6×4 B、総数と先頭順位各4 Bで320 B。最大10レコードの320 Bとunionを共用し、Storageの返送サイズ・App通知キューは増やさない。画面データの件数保持等で常駐RAMは48 B増加し、新たなヒープ・タスク・キューは追加していない。
