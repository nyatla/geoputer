# 区域アラートの実装検証

2026-10-29、Cardputer ADV通常版。仕様は[区域アラート機能設計](../15_区域アラート機能設計.md)を参照する。

## ホスト試験

- `ASAN_OPTIONS=detect_leaks=0 python3 tests/run_native.py`の既存試験が成功。設定・キーボード・GPS・UTF-8・ログ・エクスポート・USB所有権・INI等を確認した。今回追加した`run_alarms.py`と`run_audio.py`も標準入口へ登録し、それぞれ単独でも成功した。LSanは実行環境の制約で無効にし、ASan・UBSanと既存の明示的確保カウンタを使用した。
- `tests/run_alarms.py`：初回位置の無通知、階層ID列、毎回通知、A/B境界往復の抑制、3秒の再武装、第三区域、全9点一致による進入確定、欠測、消音後の抑制保持、発音時間、再通知60秒上限、Tick周回を確認した。
- 同試験で64バイトファイルの新規OFF作成・保存・全バイト改変・識別不一致・階層不一致・切断・公開失敗・同名ディレクトリ保護を確認した。旧NVS v3の選択先・言語を保持して既定音量を補い、v4の音量保存を確認した。
- `tests/run_audio.py`：全5音列、5音量、起動時一度だけのドライバ初期化、休符、明示消音、終了時のES8311パワーダウン、再通知60秒上限、I2C・再生失敗と電源停止再試行を確認した。ドライバはホスト代替であり、音圧・消費電流の実測ではない。
- `tests/run_logger_app.py`：本番Appとキュー／UIモデルを使用し、履歴座標と異なる実GPSを消灯中にも監視すること、借用領域の返却、表示地名の保持、初回無音、通知、消音と復帰、境界抑制、SD異常停止、OFF時の試聴を確認した。既存の記録・再生・地図・ファイル操作試験も成功した。
- `tests/run_borrowed_place_files.py`をN03実データで実行し、全5階層の9点検索を確認した。C++ヒープ確保0、Reader借用返却、表示Wordbook文字列のキャッシュ検索なしを確認した。
- `tools/render_settings_layout.py`：日英各24画面、計48画面を本番描画コードから240×135で生成し、文字幅・既定フォント画素・右寄せ・ライセンス表示不変を照合した。

## 実機書込みと通常起動

MAC `70:AF:09:DF:46:D0`を照合し、アプリ領域のみを書き込み、書込み後のハッシュ一致を確認した。既存NVS・SDを保持した。ファームウェアSHA-256は`57bfa0438d1aec7828ac721693326ff650af99c77b8c531c622dc53990824231`。

保存済み設定の復元、SD FAT32、データセット02、Wordbook深さ4、GPS UART・FIX、LIVEの地名表示を確認した。`_alert.dat`は`CREATED / OFF`で初期作成され、保存と再読込み照合まで完了している。Appのその時点の残スタック高水位は3,896 Bだった。全操作中の最小値とは区別する。

起動ログは[通常起動ログ](20261029_区域アラート_通常起動.log)。CDC接続前のUI初期化ログは取得できていないため、通常起動ログだけを根拠に実スピーカーの発音を確認したとは扱わない。実際の越境に伴う音声通知、音圧・電流は別途実地確認が必要である。
