# メインレイアウト1.3検証

検証日: 2026-10-15  
対象: Cardputer ADV、Live Place採用仕様1.3  

## 変更

SPDとHDGのラベルを各パネルの左上へ寄せ、縦線x=120、中央横線y=83で左右・上下を均等に分ける。SPD / HDG間の横線は左端x=0から中央の縦線x=120までとし、右側のLAT / LON / ALT / SAT欄には引かない。

速度は整数m/h、小数1桁km/h、整数km/hを切り替える。1,000m/h未満を整数m/h、1〜100km/h未満を小数1桁km/h、100km/h以上を整数km/hとする。数字は東雲16ドット、小数点は元字形の送り幅だけを8ドットにし、3桁と小数点を最大56ドットへ収める。値の右端と単位位置は固定する。

## 検証

`python3 tests/run_native.py`はUndefinedBehaviorSanitizer、-Wall / -Wextra / -Werror付きで成功した。速度0、420m/h、999m/hから1.0km/hへの繰上げ、9.96から10.0、99.96から100、999からOVRの境界を確認した。どの表記も数字3桁まで、送り幅56ドット以内となる。小数点の元字形が8ドットの送りへ収まることも検証した。

`python3 tools/render_live_place_layout.py`は通常10状態と追加10状態の20場面で成功した。x=120の縦線、y=83の横線（初回は全幅、下記修正後は左半分のみ）、SPD / HDGの左上配置と単位の位置、経度の端値・電池100%・未取得等を画素で確認した。文書用の20枚はすべて新レイアウトで置換した。

PlatformIOの通常ビルドが成功した。静的RAMは42,296 / 327,680バイト、Flashは1,051,497 / 3,342,336バイト。COM6の既知MACを照合してアプリ領域へ書込み、ハッシュ検証が成功した。SHA-256は`40964c3fe5099f056f047027625417bcd9ab7496ae7e91d945d6f7d193821633`。通常起動後30秒のUSBログで、Bootの6項目成功、Live Placeへの遷移、有効GPS Fix、JST時計、習志野市の住所検索、キャッシュのMISS後のHITを確認した。例外・アサート・再起動は検出しなかった。実寸の画素検証は実装コードを用いたホスト描画で行い、実機のLCD撮影との比較ではない。


## SPD / HDG間の横線の修正

初回の1.3で全幅へ引いた横線を、画面左端から中央縦線までの幅120ドットに修正した。速度表示・ラベル位置・均等分割は維持する。描画検証にy=83の左側が白、右側x=121〜239が黒であることを追加し、GPS詳細欄へ横線が伸びないことを20場面で確認した。通常ビルドと端末書込み・ハッシュ検証に成功し、15秒の起動ログでBoot完了・Live Placeへの遷移・GPS Fix・住所検索とキャッシュHITを確認した。例外は検出しなかった。修正版のSHA-256は`64d85e4ef5a7ea7759de94c317fdf307c4f0aaf2365de93c8f8c2d07685e391f`。
