# TAB順送りと枠付きESC・Enter

実施日: 2026-10-29。仕様は[共通キー操作](../画面・操作/共通キー操作.md)を参照する。

![キーのROMパターンを12倍で表示](../画面・操作/key-icons-preview.png)

## 操作

Vの文字／地図切替を廃止し、キー割当・フッター・Appの旧ToggleViewメッセージを削除した。数値による直接切替を維持し、TABは同じ数値の宛先を順に選ぶ。トップ画面は1→2→3→4→0→1、ログ下位画面は1→2→3→1。現在の宛先と利用不能な宛先を飛ばし、MENU・プロパティのように現在番号のない画面では最初の有効な番号から始める。次の候補がなければ何もしない。TABのマーク・文字は表示しない。

数値グループのない下位画面、確認ダイアログ、Boot、USB、メンテナンスでは切り替えない。読出し中・同期要求の応答待ちも切り替えない。消灯中の最初のTABは復帰専用。押下エッジだけを使い、保持やFnの変化で連続切替しない。ログの切替は既存の1/2/3と同じ経路なので、現在点を保持し、異なる表示への切替では再生を一時停止する。

物理TABは外部キーボードライブラリのkeysState().tabで取得する。生のKEY_TABは0x2bでASCIIの＋と同値のため、文字キーのマッピングから除外し、地図ズームと混同しない。外部ライブラリ自体は変更しない。

## フッター

ESCは24×12、Enterは16×12の四角枠付き1ビットROMパターンに変更した。y=122〜133に描き、14ピクセルのフッター内で上下1ピクセルの余白を確保する。通常文字と方向矢印はy=124・8×8のまま。キー送りはESCが24、Enterが16、その他が8ピクセル。グループ間だけ8ピクセル空け、本文・区切り線を変更しない。通常色・無効色・現在番号の強調は維持する。

## 検証

- run_native.py成功。トップ5画面の循環、MENUからの初期選択、ログ3表示の循環、地図利用不能のスキップ、単一候補・読出し中の無効、ダイアログ優先、設定下位階層・Boot・メンテナンスでの無効、消灯からの復帰、V廃止、TAB案内なし、表示幅を確認した。環境で利用できないLeakSanitizerのみ無効にし、AddressSanitizer・UndefinedBehaviorSanitizerと専用の確保回数検査は維持した。
- 実際のキーボードライブラリとADV Readerを使い、物理TABの押下・解放で特殊キーフラグを更新し、文字として返さず、ポーリングの確保・解放がゼロのままであることを確認した。
- run_logger_app.py成功。実UI→App経路でTABによる文字→地図、地図なし時の文字→統計、統計→同じ点の文字表示を確認した。ログの現在点・再生制御・統計キャッシュ等の既存試験も成功した。
- run_status_icons.pyの375ケース成功。全画面・日本語／英語・4/16ビット色でフッター14行全体を照合し、ESC/Enterの枠と内部パターン、キー位置、空白、色、下端余白を確認した。
- LIVE、設定、MENU/GPS、ログ、データセット、起動エラー、通常地図の画像を再生成した。通常地図はN03実データで1/1・1/2・1/4を描き、4/16ビット色の一致を確認した。
- cardputer-advのビルド成功。静的RAMは253,972 Bで不変、Flashは直前の数値選択版1,237,769 Bから1,237,985 Bへ216 B増加。ELFのDROMにESCの48 BとEnterの24 Bを確認した。ヒープ領域や常設の画面状態は追加していない。
