# 地図画面の文字配置検証

実施日: 2026-10-25

地図左上は表示中画像の倍率（1 / 1/2 / 1/4）だけとし、画面番号とMAPを除いた。読出し・更新中の黄色いREADING / UPDATING表示は使用しない。倍率変更中は完成画像とその倍率を保持し、新しい完成画像と一括で交換する。

地名はメインと同じformatPlaceLinesで、選択した言語のdisplay_line1 / display_line2を展開する。FrameInfoは64バイトの地名2行を保持し、文字と完成画像の世代を一致させる。下部のy=80 / 100に東雲16×16、半角スペース8×16で描く。距離目盛りは右側y=50〜66へ移動し、北矢印・現在地マーカー・地名と分離した。縦横比の補正と距離換算は維持している。

## 検証結果

- `tests/run_native.py`: キュー、UI、GPS、設定、記録、USBなどの回帰試験が成功。
- `tests/run_map_files.py`: 実データでメインと地名2行が一致。独自の書式と%%、意図した空行を確認。全倍率の区域コード・境界生成と128キャッシュの独立性を維持。
- `tests/run_map_scale.py`: Appの倍率変更、古い完了通知の拒否、転送中の切替、有効Fix復帰後の生成、完成画像の一括交換が成功。
- `tools/render_map_view.py --scales 1 2 4`: 各倍率の完成・更新中・初回読出し中・未測位・読出しエラーの計15シーンが成功。倍率だけの文字、黄色い文字の非表示、地名2行の画素、4bit / RGB565一致を確認。更新中と完成時の画面は画素単位で一致した。

掲載画像は統計区データを使い、1行目を県・市、2行目を町名とする例示書式で再生成した。実機キャプチャではない。
