# 地図倍率切替の検証

2026-10-25。地図画面の上下キーで、等倍・1/2・1/4を切り替える機能を実装した。

## 操作と更新

上キー（`;`、Fn併用も可）は1/4→1/2→等倍へ拡大し、下キー（`.`、Fn併用も可）は等倍→1/2→1/4へ縮小する。端では止まり、循環しない。起動時はConfig.hのMapViewScaleを使用する（標準は1）。選択倍率はAppがセッション中に保持し、画面を往復しても維持する。NVSへの保存は行わない。

UIはMapScale操作を通知してAppの受付結果を待つ。Appは選択倍率を更新し、進行中の地図要求を取消してから最新倍率の要求を出す。同じGPSサンプルでも通常の5秒周期を待たずに再生成する。倍率変更前の完了通知とUI転送は拒否し、古い画像の遅延到着で新しい選択を上書きしない。

完成までは表示中の地図・地名・距離目盛りを保持する。左上の倍率は表示中画像の倍率とし、更新表示には変更先の倍率を付ける。全行を受信してCommitした時点で一緒に切り替える。GPS未測位などで生成できない間も倍率選択は保持し、復旧時に反映する。消灯中の最初のキーは復帰のみとする。
