# データセット切替実装検証

確認日: 2026-10-17

## 1. 実装範囲

[データセットメタデータ仕様](../08_データセットメタデータ仕様.md)のINI読取り、01〜99の一覧・詳細・言語選択、停止完了後の保存・再起動、および選択先欠落時の起動停止を実装した。端末への書込みと実機操作試験は行っていない。

DatasetMetadataは255バイトまでの行を固定長バッファで読み、共通情報と言語識別子を保持する。全翻訳をツリーへ展開しない。UI用のタイトル・説明と地名用Wordbookは独立して選択する。言語識別子はNVSの固定領域に合わせ最大31バイトとし、行長とともにConfig.hへ定義する。BOM、CRLF、最終改行省略を許可し、不正UTF-8、重複、行長超過、必須項目不足、別ディレクトリへの参照を拒否する。

DatasetCatalogは4件の一覧を番号順に返す。一覧では候補GLCを開かず、詳細・言語変更・適用で対象だけを検証する。解像度と格納範囲はGLC、文字コードはWordbook内部から取得する。候補用PlaceLookupはヒープへ一時確保し、使用中のReader・キャッシュを差し替えない。

StorageのDatasetOperationは同期結果で受付成否を返し、ReadCompleted / ReadFailedのDatasetBrowser結果を非同期に返す。結果はtokenで照合する。読込み中に一覧へ戻る・言語を取り消す要求は既存の受信枠へ投入し、古いtokenの結果で表示が戻らないようにする。AppはSTOPPED、未保存分なし、採用点・制御操作の保留なしを確認し、Storageも保持セッションを確認する。PAUSEDや未完了の停止では適用しない。適用中はログ開始・再開を禁止する。

検証後に番号と言語を同じNVSレコードへ保存する。Appは保存成功の結果を得てから通常ループで再起動する。同じ番号・言語への適用では再起動を省き、初回・旧形式から復元した既定言語の組も明示的に保存できる。失敗時は旧保存値を維持し、再起動しない。

起動時に選択ディレクトリ・INI・GLC・言語セクション・Wordbookが見つからない場合は、起動エラーとして通常画面へ進まない。SD未挿入も同様とする。UIとAppの双方で遷移を禁止し、別の番号・言語や拡張子検索へ自動で切り替えない。

## 2. NVS形式と移行

名前空間はgeoputer、キーはconfigのままとし、形式バージョン3を48バイトで保存する。従来の項目はオフセット4〜10、言語識別子は12〜43、FNV-1a検査値は44〜47とする。ディレクトリ番号はオフセット8へ保存する。

16バイトのバージョン1・2も読み込む。従来のデータセット値0〜2は未使用の候補番号であり、フォルダ番号へ流用せず01とINIの既定言語へ移行する。他の設定は引き継ぐ。バージョン1の表示言語は日本語とし、バージョン2の表示言語は保存値を使う。読込みだけではNVSを書き換えない。

## 3. ホスト試験

`python3 tests/run_native.py`はUndefinedBehaviorSanitizerと標準ライブラリの検査を有効にして実行する。次を確認した。

- INIのセクション順序、翻訳フォールバック、UI言語と辞書言語の独立、指定言語欠落時の拒否。
- BOM・CRLF・改行なし、255/256バイト境界、UTF-8不正、NUL、重複、必須項目、未対応バージョン、パス指定の拒否。
- メタデータの成功・失敗の両経路でSDアクセス通知の開始と終了が釣り合うこと。
- 01〜99の設定値、番号と言語の保存・復元、旧形式からの移行、保存失敗後の旧レコード保持。NVSはPreferencesのホストアダプタで検証する。
- Datasetの一覧・詳細への操作、左右キーによる言語候補変更、読込み中のEscによる候補取消要求、適用中の操作・消灯抑止。
- STOPPEDとPAUSEDの区別、未保存・閉鎖中・App保留点のある場合の適用条件。
- UiModelの起動エラー状態がEnter・Esc・MENU・無操作時間で通常画面へ遷移しないこと。
- 既存の同期結果回収、GPS、設定、ログ、フォント、時計、ライセンスの試験。

## 4. 実ファイル試験

`python3 tests/run_place_files.py <GLC> <SJIS Wordbook>`でN03-20260101のgrid-4096-1000版GLCとSJIS辞書を使用した。ここでgrid-4096は配布ファイル名の一部であり、実際のGLCのunit_inv_x / unit_inv_yは1000である。

一覧の4件ページング、疎な番号、00・100・文字列フォルダの除外、翻訳タイトル、GLCからの情報取得、言語別ファイル指定、指定外ファイルの無視、指定ファイル欠落時の拒否、INI欠落後に拡張子検出へ戻らないことを確認した。1501チャンクの試験データでは上限超過として拒否する。候補検証が失敗しても、別の有効なPlaceLookupのキャッシュを壊さないことも確認した。

言語別ファイル選択の試験では同じSJIS辞書を別言語名のファイルとして配置している。これはファイル選択の確認であり、英語地名への翻訳が存在するという検証ではない。実地名の習志野市・千代田区取得と、既存の324点のキャッシュ・点検索比較も通過した。

## 5. 描画検証

`python3 tools/render_dataset_selector.py`で一覧、詳細、範囲・チャンク、適用、停止要求、保存中、起動エラーを日英で生成する。計14画面は240×135の実寸PNGとし、同じ製品Rendererの4bit・16bit出力をバイト単位で比較する。値は表示確認用であり、端末の実測値とはしない。

新しい[Settings表示例](../画面・操作/settings/README.md#8-データセット画面の表示例)と[起動エラー表示例](../画面・操作/boot/README.md#31-選択したデータセットが見つからない場合)を追加した。既存Settingsの日英22画面、全設定値の配置・字形、ライセンス本文の既存描画、Live Placeの描画も確認した。

## 6. 実機確認が必要な範囲

次の確認は実機では未実施である。

- 実SDカードの候補表示、言語変更、物理キーでの操作。
- 記録中・一時停止中・未保存分ありでの適用拒否と、停止完了後の適用。
- NVS実保存からESP.restartまでの一連の実行と、再起動後の選択復元。
- SDの欠落・指定ファイルの削除時に起動エラーで停止し、復旧後の再起動で戻ること。
- 候補検証中のヒープ最大使用量と各タスクのスタック余裕。

既存SDへ導入する場合は、選択先ディレクトリにdataset.iniが必要である。[配置用の例](../../../examples/sd/geoputer/dataset/jp-example/dataset.ini)を使用し、mapとwordbookを実際のファイル名へ合わせる。INIを配置せず新ファームを書き込むと、指定どおり選択先欠落の起動エラーとなる。

## 7. ファームビルドと生成物

PlatformIOのcardputer-adv環境で最終ビルドが成功し、コンパイラの警告・エラーはなかった。生成物は`.pio/build/cardputer-adv/firmware.bin`、保持用コピーは`.pio/dataset-switch-firmware.bin`とする。

SHA-256: `389e778ce57ed8c439cf0867f71e98f4d8c02032f6fdb13ae1e951c7ce46506e`。静的RAMは53384 B、Flash使用量は1094481 B。前回のメモリ削減版の静的RAM 51120 Bに対し、2264 B（約2.2 KiB）増加した。実機ヒープ・スタックの新しい測定値ではない。

Xtensa ELFの型情報ではApplicationは29456 B、UI要求1544 B、通常通知696 B、同期戻り値344 B、DatasetView 424 Bである。キュー数・件数、16色の画面画像、128×128の区域コード画像、1500チャンク上限、地名キャッシュ16件、記録受付64件、ログ読出し10件、SDのVFS予約3本は維持している。

ビルド・native・実ファイル・描画ログを`.pio/dataset-switch-*.log`、集計を`.pio/dataset-switch-results.json`へ保持する。検証済みのソースから生成したバイナリであることはビルド完了時刻とソース更新時刻でも確認した。
