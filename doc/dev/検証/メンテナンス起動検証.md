# F1メンテナンス起動の検証

2026-10-21、Bootとエラー画面から設定へ退避する経路を追加した。

## 動作

- 通常起動はUI・Storage・NVS設定復元を先行し、その後1500msのF1受付期間を置く。
- F1（Fn＋1）を電源投入時から保持した場合も、UIが最初の画面指定まで操作を保持する。
- F1選択時はGPSタスク開始とCheckDatasetの投入を省き、メンテナンスのSettingsへ移る。
- 確認中・完了後・データセット欠落のBoot画面もF1を受け付ける。
- 起動後のエラー表示では、記録停止・保存・セッション終了の完了後にF1で入れる。記録中の状態をF1で変更しない。
- メンテナンスでは自動位置検索・記録開始・画面消灯を禁止する。Esc / Delは取消を初期選択とする共通再起動確認となる。
- 新規の自動読込みは抑止するが、開始済みのStorage処理は強制中断しない。読込みで再起動する場合は、次回起動からF1を保持する。
