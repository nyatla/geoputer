# Geoputer データセットメタデータ仕様

文書状態: 採用仕様1.15（識別名ディレクトリを採用。INI形式バージョン1を維持）

更新日: 2026-11-13

対象: microSD上のGaluchatデータセットに付属するメタデータ

## 1. 目的と適用範囲

本書は、データセットのタイトル、短い説明、使用するGLCおよび言語別Wordbookの対応を定義する。識別名ディレクトリごとに小さなテキストファイルを配置し、固定長の行バッファで順次処理できる形式とする。JSONや汎用INIの全機能は使用しない。

解像度、格納範囲、チャンク数はGLCを正本とし、本メタデータへ重複して記載しない。Wordbookの文字コードはWordbook内部のメタデータから判定する。

本書はファイル形式と、データセットの選択・保存・再起動・起動失敗の条件を定義する。タスク通信は同期で受付・非同期で結果通知するDatasetOperationを使用し、NVS保存は設定レコードの形式バージョン6を使用する。タスクの責務は[タスク構成設計](06_タスク構成設計.md)、配置と利用条件は[システム構成設計](04_システム構成設計.md#6-galuchatデータ)に従う。

## 2. 配置とデータセットの単位

SDカードの`/geoputer/dataset/<識別名>/`を、それぞれ独立したデータセットとする。識別名は小文字ASCIIで始まる1〜15文字とし、以降は小文字ASCII・数字・ハイフンを使う。ハイフンの連続と末尾使用は認めない。規則外のディレクトリは一覧の候補にしない。各ディレクトリ直下にメタデータ`dataset.ini`を1個、使用する共通のGLCを1個、Wordbookを言語ごとに配置する。

```text
/geoputer/dataset/
├ jp-n03-y2026-1/
│  ├ dataset.ini
│  ├ municipality.glc
│  ├ municipality-ja.giswordbook
│  ├ municipality-en.giswordbook
│  └ _mapindex.dat
└ jp-est-y2020-2/
   ├ dataset.ini
   ├ town.glc
   └ town-ja.giswordbook
```

パスはSDカード内の表記とし、本体のマウント先を含める場合は`/sd/geoputer/dataset/jp-n03-y2026-1/dataset.ini`となる。識別にはディレクトリ名を使い、翻訳や編集によって変わるタイトルを識別子として使用しない。ディレクトリ識別名をINI内へ重複して記載しない。

地図とWordbookのファイル名はINIで明示する。拡張子に一致するファイルが別に存在しても、指定されていないファイルを自動選択しない。

### 2.1 固定ルートと識別名

本体で使用するルートは`/sd/geoputer/dataset/`で固定し、変更項目やNVSの文字列として保持しない。選択中の識別名はStorageが終端込み16バイトの固定領域で保持し、空文字列を未選択とする。NVS形式バージョン6には識別名と言語を一組で保存する。従来の番号のみを保存したバージョン1〜5は番号を識別名へ推測変換せず、未選択へ移行する。ほかの設定値は維持する。

### 2.2 地図名と辞書名の容量

`map`と各言語の`wordbook`は、拡張子を含むファイル名全体をそれぞれUTF-8で最大127バイトとする。終端NULを含め各128バイトの固定領域に保持する。127文字ではなく127バイトの制限であり、日本語等の複数バイト文字も同じ規則で数える。128バイト以上の値は、その言語が未選択でも不正なメタデータとして拒否し、切り詰め・別名への置換・文字コード変換を行わない。

選択中の実行情報はStorageが固定メンバーとして所有し、識別名と、使用するGLCのファイル名・選択言語のWordbookファイル名の２つを保持する。Appはこの選択中実行情報の本体や参照を保持せず、要求と完了通知を仲介する。名前用の固定領域は`map_name[128]`と`wordbook_name[128]`の合計256バイトとし、容量定数は`application/Config.h`の`DatasetFilenameBytes = 128`へ集約する。言語・表示書式・検証済みヘッダー等の情報とその容量は、この名前の上限とは別に扱う。

ディレクトリ、GLC・Wordbookのフルパス、索引のフルパスはセッションに保存しない。`dataset.ini`、`_mapindex.dat`、索引公開用の`_mapindex.tmp`と`_mapindex.bak`は固定名とする。各ファイル操作で、固定ルート・識別名・ファイル名からパスを組み立てる。組立先はシステム共通の終端込み256バイトのスタック領域とし、終端を除く255バイトを超えた場合はエラーにする。

例として識別名`jp-n03-y2026-1`・`map=municipality.glc`は`/sd/geoputer/dataset/jp-n03-y2026-1/municipality.glc`となる。識別名とファイル名の上限を守れば共通の一時パス容量に収まる。NVS形式は6へ更新し、INIのキーと形式バージョン1、索引のバイナリ形式は維持する。

## 3. テキストと読取り規則

| 項目 | 規則 |
|---|---|
| 文字コード | UTF-8。BOMなしを基本とし、先頭のUTF-8 BOMは許容する |
| 改行 | LFまたはCRLF。最終行の改行は省略できる |
| 行の長さ | ファイル先頭のBOMと改行を除き最大255バイト。UTF-8の文字数ではなくバイト数で数える |
| 空白 | 行頭・行末、およびキー・値の前後のASCII空白とタブを除去する。値の内部の空白は保持する |
| 空行 | 無視する |
| コメント | 行頭の空白除去後に`#`で始まる行を無視する。行末コメントは扱わない |
| セクション | `[dataset]`または`[言語識別子]`とする。閉じ括弧の後には空白以外を置かない |
| 項目 | 最初の`=`でキーと値を分ける。以後の`=`は値の一部とする |
| 引用・エスケープ | 解釈しない。引用符やバックスラッシュは文字として扱う |
| 複数行の値 | 使用しない。タイトルと説明も各1行とする |
| 大文字・小文字 | セクション名とキー名は区別し、本書の小文字表記を使用する |

最初のセクションより前に項目を置かない。同じセクション名を複数回宣言せず、同一セクションの定義済みキーを重複させない。行長超過、UTF-8の不正なバイト列、NUL、構文に合わない行は不正なメタデータとして扱う。行を切り詰めて解釈しない。

形式バージョン1における未知のキーは無視する。セクションは共通情報と言語情報だけを使用し、任意の独自セクションは設けない。既知項目の意味を変更する場合は形式バージョンを変更する。

解析は`readDatasetMetadataInto`で呼出し元の固定出力先へ行う。地図名・選択言語の辞書名は各128バイト、言語IDは32バイト、書式は各128バイトを用い、実行用の結果にタイトル・説明・全言語一覧を含めない。タイトル・説明はUIの借用返却領域へ直接書き、表示側の容量を超えた部分はUTF-8の文字境界で省略する。INI原本は変更しない。

言語ID一覧は16×32＝512バイト、行バッファは256バイトの局所配列とし、現在セクション・既定言語・カウンタも解析関数内のスタックへ置く。言語の重複検出、既定言語と指定言語の存在確認、UI翻訳の選択を行った後、現在言語・件数・位置を返す。言語切替は同じ2回のINI走査内で前後のIDを確定し、切替先を得るための追加の解析を行わない。索引保守で全言語の列挙が必要な場合だけ、局所一覧のコピーを明示的に要求する。表示側や選択中セッションには一覧を保持しない。

解析の局所領域を持つ関数はReaderによる地図・辞書の処理へ入る前に戻る。永続化する実行情報は解析成功を確認してからStorageのSelectedDatasetへ反映する。標準IO内部の確保は対象外だが、解析結果のstring・vectorとアプリ側の通常経路の動的確保は使用しない。

読取りは1行ずつ行い、一覧や選択中の表示に必要な項目だけを保持する。全ファイルの読込みや、全言語を動的なツリーへ展開することを前提にしない。行の格納には終端NULを含め256バイトを用意し、改行の処理で行長上限を超えて格納しない。実装時の行長上限は、他の容量設定と同様に`application/Config.h`へ集約する。

## 4. セクションと項目

### 4.1 共通情報 `[dataset]`

| キー | 必須 | 内容 |
|---|---|---|
| `version` | 必須 | 本形式のバージョン。値は`1`とする |
| `map` | 必須 | 使用するGLCのファイル名。拡張子`.glc`を含め最大127バイト |
| `default_language` | 必須 | データセットの既定言語。対応する言語セクションが存在すること |

各値は空にしない。共通情報セクションは1個とし、言語セクションとの記載順序は問わない。

### 4.2 言語情報 `[ja]`、`[en]`等

言語識別子はASCII小文字の英字から始め、小文字英数字のまとまりをハイフンで区切る。`ja`、`en`、`en-us`等を使用できる。空の識別子、先頭・末尾のハイフン、連続するハイフンは使用しない。言語識別子は最大31バイトとし、終端NULを含む32バイトの固定領域で扱う。`dataset`は共通情報のために予約する。

| キー | 必須 | 内容 |
|---|---|---|
| `title` | 必須 | その言語で表示する短いデータセット名。空にしない |
| `description` | 任意 | その言語で表示する短い説明。省略または空の場合は説明なしとする |
| `wordbook` | 必須 | その言語のWordbookのファイル名。拡張子`.giswordbook`を含め最大127バイトとし、空にしない |
| `display_line1` | 任意 | 地名の1行目の書式。省略時の扱いは5.1節に従う |
| `display_line2` | 任意 | 地名の2行目の書式。空文字も指定できる |

言語セクションは1個以上16個以下とする。上限は`application/Config.h`の`MaxDatasetLanguages = 16`へ集約する。17個目はメタデータエラーとし、言語の切り捨てや動的領域への退避を行わない。言語識別子は地名の言語を表し、文字コードを表さない。各言語のWordbookはUTF-8で、共通GLCの区域コードに対応する辞書であることを配布物の条件とする。言語の一致だけで区域コードの対応が保証されたとは扱わない。

`map`と`wordbook`は同じディレクトリ直下のファイル名だけを指定する。絶対パス、サブディレクトリ、`/`・`\`・`:`を含む指定、`.`と`..`は認めない。別の識別名ディレクトリのファイルを参照しない。

## 5. 表示と言語の扱い

一覧は識別名とタイトルを表示し、説明は詳細表示用に使用する。タイトル・説明はUIの表示言語に一致するセクションを使用し、該当セクションがない場合は`default_language`のセクションを使用する。画面に収まらない文字列はUTF-8の文字境界を保って表示側で省略し、保存内容自体は切り詰めない。

UIの表示言語と、地名取得に使うWordbookの言語は別の情報として扱う。日本語UIで英語地名を表示する組合せも表現できる。データセットを初めて選択した場合は`default_language`を地名用言語の初期値とし、詳細画面で収録されている別の言語へ変更できる。UIの表示言語を変更するだけでは、選択済みのWordbookを変更しない。選択したディレクトリ識別名と言語識別子を一組としてNVSへ保存する。

本形式による言語の記載は、端末にその言語のフォントが実装されていることを保証しない。描画可能な文字とレイアウトは画面共通仕様に従う。

### 5.1 地名2行の書式

地名用Wordbookの言語セクションに`display_line1`と`display_line2`を置き、Wordbookから区域コードに対応して取得した文字列配列を2行へ展開する。タイトル・説明とは異なり、書式はUI言語ではなく選択中のWordbook言語に従う。

各書式は終端NULを含めて128バイトの固定領域へ保持し、有効長はUTF-8で最大127バイトとする。127文字ではなくバイト数で数える。前後の空白を除いた値が128バイト以上の場合は、未選択言語の書式でも不正なメタデータとして拒否し、切り詰めない。容量は`application/Config.h`の`PlaceFormatBytes = 128`を正本とする。Storage所有の選択情報は書式2行と選択言語32バイトを固定配列で保持し、地名・地図読出しが参照する。選択情報の保持・コピー・解除で文字列のヒープ確保を行わない。INI解析中の言語一覧等の局所スタックと、UIへ直接出力するタイトル・説明は、この保持領域とは別である。

```ini
[ja]
title=日本・住所
wordbook=address-ja.giswordbook
display_line1=%0 %1%2%3
display_line2=%4%5
```

| 記法 | 展開 |
|---|---|
| `%0`〜`%9` | 0始まりの項目番号。配列の順番をそのまま参照する |
| `%%` | 文字としての`%` |
| その他の文字 | 固定文字として表示する |

項目が空文字、または配列に存在しない場合は空文字を展開する。隣接する固定スペースは自動削除しない。番号は1桁のみとし、`%10`は`%1`と固定文字`0`となる。項目の内容は再解釈せず、そこに含まれる`%`をそのまま表示する。末尾の単独`%`や`%A`などは不正な書式とし、一覧・詳細・適用時のメタデータ検証でエラーにする。使用しない言語の不正書式や同じキーの重複も検出する。行長・UTF-8・前後の空白除去は既存のINI規則に従い、引用符やバックスラッシュでのエスケープは追加しない。

両キーを省略した場合は従来の配置とする。6項目のWordbookでは先頭項目と項目1〜3を1行目へ、項目4・5を2行目へ連結し、それ以外の項目数では先頭項目と残りを1行目にまとめる。先頭項目と残りの行政名がともにある場合だけ間に半角スペースを入れる。N03の5項目で従来表示を明記する例は`display_line1=%0 %1%2%3%4`、`display_line2=`となる。

片方だけ指定した場合は未指定の行を空とする。両方を空文字に指定すれば地名の2行を空表示にできる。上下行を自動的に結合したり、あふれた文字を他方へ送ったりしない。

書式展開の結果は2つの論理行とする。画面への配置は[Live Place](画面・操作/live-place/README.md#4-検索と表示更新)と[地図画面](画面・操作/place-view/README.md#表示)の仕様に従う。`ja`は東雲16×16で、半角スペースU+0020だけ8ドット幅とする。日本語以外のASCIIは通常AsciiFont8x16で、非ASCII文字は16ドット幅とする。全角スペースU+3000は16ドット幅を維持する。Live PlaceのASCII長文は、論理行ごとに8×8の最大2表示行へ折り返す。地図画面は各論理行を1表示行で省略する。書式展開は固定長の行バッファを使い、長い項目や繰返し参照でも連結後の巨大な文字列を確保しない。

Storageは展開した2つの論理行を地名キャッシュへ保存し、Appへ値コピーで通知する。Appは再結合せず、そのままUIへ渡す。Live Placeの折返し判定より前に232ドットで省略しない。画面ごとの折返し・省略はUIで確定する。地名キャッシュとUIの論理行は各96バイトとし、Live PlaceのASCII最大2表示行と地図1行目の日本語8×8表示に必要な範囲を保持する。書式はデータセットを開く際に読み込み、変更はSD上のINIを更新した後に再起動または再マウントして反映する。Readerの再オープン時に旧書式のキャッシュを破棄する。形式バージョンは任意キー追加として1を維持し、NVSの保存形式も変更しない。

## 6. GLC・Wordbookとの役割分担と検証

実行中に参照するSelectedDatasetはStorageが固定領域へ保持する。Appは解析済み情報を永続保持しない。UI表示用のタイトル・説明・候補・言語の現在位置は画面からの要求時に取得し、UIが貸す既存back画像のDatasetViewへ直接書き込む。Appはアドレスと完了通知を仲介し、UIが結果を取り込んで借用を返す。言語一覧全体はUIへ保持せず、現在言語・件数・位置と次候補の問い合わせを使う。画面切替後の結果は表示せず、書込み終了後に必ず借用を返す。

候補のGLCとWordbookの確認は、Storageの既存96 KiBから読出しバッファを借りる。Wordbookは保存索引を必要としないWordBookHeaderReaderでGW00・TM00・TT00・TI00の標準ヘッダー、境界、ビット幅の対応を確認し、起動時の確認でも同じReaderを使用する。GW00の任意メタデータは内容を保持しない。確認のためにSDKのFactoryやWordbook Readerのインスタンスを生成しない。借用により保持地図は無効化されるが、使用中の選択情報・地名キャッシュ・NVSは変更しない。

一覧取得ではINIを読み、全候補のGLC本文や索引を読み込まない。説明とWordbookの対応は必要時にINIを読み直して取得できる。GLCからの情報取得・利用条件の検証は対象の選択時に行う。INIの読取り成功だけを、使用可能判定としない。

| 情報 | 正本と取得方法 |
|---|---|
| タイトル・説明・言語別ファイルの対応 | `dataset.ini` |
| 経度・緯度方向の解像度 | GLCの`unit_inv_x`・`unit_inv_y`。1セルの角度幅はそれぞれ逆数で表す |
| 格納範囲 | GLCの各チャンクの位置・幅・高さから求める。全体の外接矩形にはデータのない隙間を含み得る |
| チャンク数 | GLCから取得し、最大1500チャンクの利用条件を適用する |
| Wordbookの文字列の扱い | アプリはUTF-8として読み、実際に取得した地名のバイト列を検証する。GW00の任意メタデータは利用条件にしない |

解像度は角度単位であり、固定のメートル値とは扱わない。INIへ範囲・解像度・チャンク数・文字コードを追記しても、それらを本体データの代わりに使用しない。

INI・Wordbook・タスク間メッセージ・UIの文字列はUTF-8として扱い、端末内で文字コードを変換しない。Wordbook形式は文字コード宣言を必須としていないため、GW00の任意メタデータの省略、独自項目の有無、`token_encoding`や`text_encoding`の値で使用可否を判定しない。メタデータの長さとチャンク境界は確認し、内容は解釈せず読み飛ばす。索引の同一性確認に使うヘッダーCRCの範囲は変更しない。実際に読む地名に不正なUTF-8のバイト列があればEncodingErrorとし、地名キャッシュに登録しない。不明文字への置換・文字コードの自動判定は行わない。ヘッダー確認時に全地名を走査することは要求しない。

既存のSJIS版Wordbookを使用していたSDカードは、同じGLCに対応するUTF-8版Wordbookを配置し、INIの`wordbook`をそのファイル名に更新する。ファイル名や文字コード宣言だけの変更ではデータ本体を変換できない。GLC・INIの形式バージョンとNVS設定レコードの形式は変更しない。

適用前には指定したGLCと使用対象のWordbookの存在、対応するファイル形式、およびGLCのチャンク上限を検証する。地名のUTF-8妥当性は読出し時に検証する。指定ファイルが不足している場合に、別のファイルを拡張子で検索して代用しない。

## 7. 異常時の扱いと現行実装との区別

| 状態 | 扱い |
|---|---|
| `dataset.ini`が存在しない、または読み取れない | メタデータを利用できないデータセットとして扱う |
| 構文不正、行長超過、必須項目の不足、セクション・定義済みキーの重複 | 不正なメタデータとして扱う |
| `map`またはいずれかの`wordbook`が128バイト以上 | 不正なメタデータとして扱い、切り詰めず拒否する |
| `version`が`1`以外 | 未対応のメタデータ形式として扱う |
| 既定言語のセクションが存在しない | 不正なメタデータとして扱う |
| 指定したGLC・使用対象のWordbookが存在しない | 対象ファイル不足として扱う |
| GLC・Wordbookの形式不正、読出し失敗 | 本体データの検証エラーとして扱う |
| 読み出した地名が不正なUTF-8 | EncodingErrorとし、地名キャッシュへ登録しない |
| GW00任意メタデータの省略・独自文字コード項目 | 使用可否の判定に使わない。長さ・チャンク境界は検証する |
| GLCが1501チャンク以上 | チャンク上限超過として扱い、地図本文の検索へ進まない |

不正なデータセットを新たな選択値として適用・保存しない。検証失敗時は以前の有効な選択と保存値を維持し、再起動しない。使用中の選択先が起動時または検索中に利用できない場合は、8.3節に従って原因を通知して未選択へ移り、通常起動・GPS受信を継続する。

2.1〜2.2節の識別名・固定ファイル名保持・Storage所有の固定領域を読出し処理が借りる方式と、メタデータ読取り、一覧・詳細・言語選択、停止完了条件、NVS保存後のReader切替に加え、8.3〜8.4節の使用不能時の自動解除・診断通知・再読込み抑止を実装した。検証範囲は[データセット異常時の起動継続検証](検証/データセット異常時の起動継続検証.md)を参照する。

## 8. 選択・保存・適用

### 8.1 選択画面

動作設定の「データセット」で3項目のメニュー（データセットを選択、キャッシュ再生成、キャッシュ検証）を開く。「データセットを選択」から未選択と識別名・タイトルの一覧を開く。上下キーで選択し、Enterで詳細を開く。詳細にはタイトル、説明、GLCから取得した解像度・格納範囲・チャンク数、地名用Wordbookの言語を表示する。地名用言語はUIの表示言語と独立して選択できる。Esc / Delで戻る操作や候補の変更だけでは、使用中のデータとNVSを変更しない。

### 8.2 変更の前提と適用

データセットまたは地名用Wordbookの言語を変更して適用する前に、GPSログの停止が完了していなければならない。一時停止のPAUSEDは停止完了として扱わない。STOPPEDに加え、未保存レコードの保存、保持中の採用点の処理、セッションの閉鎖まで完了していることをAppが確認する。変更のために記録を自動停止せず、条件を満たさなければGPS Loggerで停止するよう表示する。

適用操作は「適用する」として示す。8.6節に従い、候補の検証後・NVS保存前に索引の生成と正式ファイルの確定を行う。Appが停止完了条件を再確認し、候補のGLCと使用対象のWordbookを検証した後、識別名と言語の組をNVSへ保存する。実保存成功後、Storageが旧Reader・矩形キャッシュ・地名キャッシュを解放し、新しい組でReaderを構成する。Appは地名表示をクリアしてCheckDatasetを要求し、新世代の確認結果を受けて検索を再開する。GPS・UIタスクは再起動しない。同じ識別名・言語の再適用でもReaderを再構成する。

適用の受付後から検証・保存・Reader切替までの間は、ログの開始・再開を受け付けない。検証または保存に失敗した後は、旧選択と旧有効索引を維持して通常操作へ戻す。保存成功後の再確認で実データが使用不能と判明した場合は、8.3節の自動解除を適用する。

### 8.3 起動時の復元とエラー

起動時はNVS形式バージョン6から識別名と言語の組を復元する。未保存・設定初期化後は未選択とする。形式バージョン1〜5の旧番号選択は未選択へ移行し、ほかの設定値を維持する。

使用中のデータセットが利用不能と判明した場合、Storageは原因をRAM上の診断情報へ記録し、空の識別名・Wordbook言語をNVSへ保存して未選択へ移す。Reader・矩形キャッシュ・地名キャッシュを解放し、RGを未準備とする。定常的な選択状態は未選択と使用可能な選択済みに整理し、使用不能な選択を維持しない。

対象はINI・地図・Wordbook・事前索引の欠落、構成・形式・文字コード不正、チャンク上限超過、メモリ不足、検索・読出し失敗、およびSD未挿入・非対応・マウント失敗などの媒体利用不可とする。保存済み選択のキャッシュを削除して起動した場合も、自動生成せずエラーを通知して未選択にする。単なるGPS Fixなし、範囲外・区域コード0は解除理由にしない。

BootではGALUCHAT DATAに検出した原因を示し、解除先NONEを下部に表示して起動を継続する。Live Placeの地名2行は「データセット／未選択」とし、原因をASCII 8×8の赤帯で5秒間通知する。画面消灯中・他画面表示中に発生した通知は、Live Placeを表示してから表示時間を数える。原因はその起動中のデータセットメニューでも確認できる。診断情報はRAMだけへ保持し、次回起動へ持ち越さない。

解除のNVS保存に失敗してもRAM上の選択とReaderは解除する。保存失敗フラグとNVSエラーを通知し、BootのNVSチェックおよび通常画面に保存失敗を示す。旧選択がNVSに残る可能性があるため、次回起動では再度検証される。一度未選択へ移った後は、GPS更新などを契機にNVS書込みを繰り返さない。以後の設定保存が成功した場合に保存失敗表示を解除する。

新しい候補の詳細検証・適用に失敗した場合は、現在の有効な選択を維持する。別の識別名のキャッシュ保守の失敗でも使用中の選択を解除しない。候補の検証中に共有媒体そのものの利用不可が判明した場合は、使用中も利用不能となるため自動解除の対象とする。

### 8.4 未選択への退避と復旧

Storageは失敗結果と診断情報を完了通知へコピーし、AppはStorageが確定した未選択の設定を採用する。解除の永続化に失敗してSettingsStateがFailedでも、RAM上の未選択を採用する。検索結果のDatasetInfoは未選択の新しい世代を返し、失敗原因は結果・診断情報に残す。古い成功結果やGPS Fix再取得で選択を復活させない。

自動解除は地名機能だけを停止する。GPS受信・記録状態・未保存レコードを変更せず、記録中も解除できる。利用者による選択変更・解除では従来どおり記録停止・保存・閉鎖完了を必要とする。ログ自体の保存失敗はログの保護規則に従って別途扱う。

未選択へ移った後は、GPS更新・画面復帰・再マウント・再起動で元の識別名を自動復元しない。必要なら対象一覧からキャッシュを再生成・検証し、利用者がデータセットを改めて選択・適用する。キャッシュ保守の成功だけでは選択しない。SDを一時的に取り外した場合も、選択解除が保存されれば再選択を必要とする。

通常モードでのSD取り外し・マウント失敗やフォーマット後のデータ欠落も、この規則で扱う。USBマスストレージへの正常な所有権移行はデータセット異常として扱わず、保存された選択を維持する。Escによる読込み前のメンテナンス経路と通常の設定画面は維持する。

### 8.5 検証記録と表示資料

自動解除方式は2026-10-23の実装を正本とする。旧検証記録・地名欄へ原因2行を保持する画像は、検証当時の動作を示す。現行では地名欄を未選択にし、一時通知とデータセットメニューの診断へ原因を分離する。事前索引の生成・永続化と読み出しの方式は8.6節に従う。

### 8.6 事前索引の生成と利用

[データセット事前索引ファイル仕様](11_データセット事前索引ファイル仕様.md)の `_mapindex.dat` に、GLCのチャンク・ブロック群と、WordbookのTI00・TT00・TM00の索引をまとめる。少なくとも選択する地名用言語のWordbookを収録し、他言語の同時収録は必須としない。INIのキー・形式バージョンは変更しない。

適用・再適用ではINIの全地名用言語を収録し、有効な既存領域を再利用して欠落・不一致の部分を生成する。設定からの明示再生成は対象の元データを再走査する。8.2節の停止条件を満たし、一時ファイルへの生成・検証・正式索引の確定に成功した後でNVSを保存し、Readerとキャッシュを再構成して即時反映する。生成・NVS保存失敗では旧選択と旧有効索引を維持する。

新経路では索引を必須とし、索引の欠落、構造・CRC不正、元GLCとの不一致は8.3〜8.4節のデータセットエラーに含める。選択言語領域がない場合と元Wordbookのファイル名・サイズ・FAT更新日時・GW00 CRCの不一致も同様に扱う。起動・再マウントでは既存索引を検証するだけで、自動生成や従来の索引なし探索へ切り替えない。元ファイルを修復しただけで索引も正常化したとみなさず、必要なら明示再生成する。Escメンテナンスと通常設定からの復旧経路を維持する。

現行版は適用時にINIの全地名用言語のWordbook索引を収録し、通常起動と画像キャッシュミス時に保存チャンク索引を利用する。全体CRC・元GLCHの照合は起動・明示再検証時に行い、通常検索はSeek＆Readで必要な情報を読む。独立した再生成・元データ突合は設定→動作設定→データセットから実行する。候補検証には索引を要求しない。地名キャッシュのミスでは保存Wordbook索引も利用し、選択言語領域の存在・元Wordbookの識別情報・共通ヘッダーを起動時に照合する。機能別の起動継続・GPSログの利用条件は維持する。

### 8.7 データセット未選択

データセットを使用しない状態を未選択とする。設定レコードの未選択、空のWordbook言語で表し、NVS形式バージョン6は識別名を終端込み16バイトで保存する。未選択なのに言語が残るレコードは不正として拒否する。設定未保存、不正設定からの初期値適用、設定初期化後はこの状態を使用する。

未選択ではINI・GLC・Wordbook・索引を自動で開かず、地図ラスタと地名キャッシュを保持しない。GPS Fix取得、画面復帰、SD再マウント、データセット確認要求でも読込みを開始しない。BootのGALUCHAT DATAは正常完了の`NONE`とし、未選択だけを理由に警告待ち時間へ延長しない。Live Placeの地名2行は日本語で「データセット」「未選択」、英語で`DATASET` / `UNSELECTED`と表示し、未選択を赤帯のエラーにはしない。SD・GPSなど別機能の障害は従来どおり表示する。

GPSの現在情報、SDと有効Fixを使うログ記録、既存ログの操作、設定、USBモードは各機能の条件に従って使用できる。逆ジオコーディングを実行せず、保守対象未選択も受け付けない。使用中が未選択でも、キャッシュ再生成・検証の一覧で実在する識別名を選んで保守できる。ユーザーが選択一覧を開く操作は明示的な候補読込みとして扱う。

設定→動作設定→データセット→「データセットを選択」の一覧先頭にある「未選択 / None」で共通確認を開く。独立した解除メニューは設けない。取消を初期選択とし、右で解除を選びEnterで確定する。GPSログの停止・未保存データの保存・セッション閉鎖完了を必要とし、記録中・一時停止中やStorage処理中には解除しない。解除はNVSへ未選択と空言語を一括保存し、成功した時点でReaderを閉じて地名表示を消す。再起動は不要である。SDや現在のメタデータ・索引を読むことを前提にせず、現在のデータが欠落・破損していても操作できる。保存失敗時は旧選択を維持して失敗を表示する。SD上のファイルと索引は削除しない。

設定初期化で選択を解除する場合も同じ停止条件を適用する。未選択からの新規選択は既存の一覧・詳細・適用するを使用し、候補と索引の検証・NVS保存に成功してから切り替える。候補の検証失敗だけで未選択状態をデータセット異常に変更しない。

## 9. 記述例

以下は形式の記述例であり、各言語の実ファイルが配布済みであることを示すものではない。

```ini
[dataset]
version=1
map=municipality.glc
default_language=ja

[ja]
title=日本・市区町村
description=市区町村単位の行政区域データ
wordbook=municipality-ja.giswordbook

[en]
title=Japan Municipalities
description=Municipality boundaries in Japan
wordbook=municipality-en.giswordbook
```

保存索引は地図とINIの全地名言語のWordbookを1ファイルへ収録する。適用時は保存済み索引を全体として検証し、有効ならそのまま利用、不足・不正なら全体を再生成する。設定→動作設定→データセットのキャッシュ再生成・キャッシュ検証で、対象識別名を選び地図と全言語Wordbookを一括処理する。通常起動の軽い確認と、明示操作による元データの全走査突合を区別する。詳細は[データセット事前索引ファイル仕様11節](11_データセット事前索引ファイル仕様.md#11-索引保守と全言語の利用)に従う。

## データセット別アラートファイル

各識別名ディレクトリの`_alert.dat`はデータセット別のアラート設定とする。メタデータの言語一覧やNVSへ同じ設定を複製しない。欠落時はOFFで新規作成し、選択地図・Wordbookとの不整合時はエラーを表示してOFFで再作成する。保存中のみ`_alert.tmp`と`_alert.bak`を使用する。[区域アラート機能設計](15_区域アラート機能設計.md)に従う。
