# 共通ステータスアイコン

全画面共通のSDカードアイコンを共通ヘッダー内(x=166、y=2)へ12×12ドットで配置する。非アクセス時は暗灰の輪郭・端子・SD字形、実アクセス中は青い本体に白い輪郭・端子・SD字形とし、短いアクセスも最低150ms表示する。形は角を斜めに切ったカード本体と3本の端子、内部の3×5ドットのSD字形とする。外側の文字ラベル・囲み枠は付けない。確認ダイアログやUSBの取り外し待ちでもアイコンを暗くしない。RGの表示は廃止する。

GPSアプリではベルを含むx=148〜239、y=0〜15を予約し、タイトル・件数は右端x=144までに配置する。USB・Wi-Fiではx=162〜239、文字右端x=158とする。GPSの起動・LIVE・地図・GPS/LOGGER・ログの全階層・メニュー・設定の全階層はGpsUiRenderer、USB・Wi-FiはPanelRendererで共通デザインを描画する。画面消灯時は従来どおり描画しない。

全画面にSDカード→電池アイコン→残量率の共通表示を置く。LIVE・MAP・GPS/LOGGER・LOGSの上段は記録状態→現在時刻→ベル→SDカード→電池・残量率の順とする。ログ地図だけは左側をPLAY/PAUSE・方向・再生倍率とし、現在時刻・保存時刻は表示しない。右側のベル・SD・電池・残量率は同じ配置とする。電池本体はx=180、残量率は右端x=236へ揃える。カードは固定の本体・輪郭パターンで色を切り替え、点灯時に位置・形・大きさを変えない。

`application/task/ui/SdCardIcon.h`の12行×uint16_tの本体・輪郭2面、計48バイトのconstexprパターンをFlash/DROMへ格納する。実行時の画像生成・動的確保は行わず、既存のUIフレームバッファへ直接描く。灰色は準備状態・エラー状態を示すものではなく、SDアクセスが表示対象になっていないことだけを示す。

SD点灯の対象はログ、地図、Wordbook、索引・データセット操作、ファイルシステム管理、USB経由の実セクタ読書きとする。RAMの検索、記録受付、NVS設定保存だけでは点灯しない。保存成功・失敗の判定には使わず、エラー内容は既存の状態表示へ出す。

通常のSD I/OはStorageObserverで開始・終了を記録する。USBコールバックは実セクタI/Oの件数と実行中フラグだけをatomicで保持し、Storageタスクが取り出して既存のSdAccessChangedへ合流させる。USBコールバックからAppのキューやStorageの状態を直接変更しない。短いアクセスは件数を保持するため、Storageの次のループまでに終了しても表示対象から落ちない。

UIは新しいaccess_idを受けると最低150ms点灯し、長いアクセスはactive=falseまで維持する。開始・終了がまとめて届いた場合も短い点灯を行う。画面遷移や古い表示スナップショットで新しいアクセス情報を巻き戻さない。

`python3 tests/run_status_icons.py --output .pio/sd-icon-checks/previews`で、日本語・英語、4bit・RGB565、全画面・設定/USBの全ページ、点灯/非点灯、充電・低残量・不明状態、ダイアログと読込み状態、ベルと画面名表示の439ケースを検証する。通常のUSB並行I/O回帰試験でも、PC読書きと実行中状態、無アクセス要求の扱いを確認する。

## ヘッダー内の情報配置

ベルを含むGPSの共通表示領域はx=148〜239、y=0〜15とし、SDはx=166・y=2の12×12、電池本体はx=180・y=3の18×10と端子2×4、残量率は右端x=236・y=4へ揃える。残量率は8×8 ASCIIで100%と残量不明の--%を表示する。電池は4段階で、10%以下を赤、20%以下を黄、それ以外を緑とする。充電が確認できた場合は枠をシアン、不明または未充電は白とする。電池情報はUIの既存の5秒周期で全画面共通に更新する。

主要画面の記録状態はx=4、現在時刻はx=60、文字上端y=4へ固定する。ログの文字表示はPOINTと点番号/総件数、地図表示の点番号は地図上段へ移す。ログ一覧は内容を検査せずサイズ由来の件数を示し、ログを開いた後の異常は本文へ表示する。USBのトップタイトルはUSBとし、媒体状態をx=158までに表示する。設定の補助GPS状態表示は省き、GPS画面とLIVEの情報で確認する。ライセンスの行番号はx=80〜131に収める。

## 読込み中の表示

単純なREADING...・LOADING...・読込中ですは表示せず、実アクセスのSDカードアイコンで示す。読み込み中の二重操作防止、既存の有効な内容の保持、空一覧を誤表示しない判定は維持する。削除中、ログ終了時のSAVING、データセット適用・索引再生成・検証、エクスポートは操作の意味や進捗が必要なため残す。エラーのREAD ERROR等も維持する。


## 実装検証

現行の48バイトのSDアイコン、ログ一覧、直接閲覧とメモリ使用量の検証は[ログ一覧と直接閲覧の検証](../検証/ログ一覧と直接閲覧の検証.md)を参照する。全画面・電池状態を含む279ケースと、更新後の原寸画像を確認し、通常ファームを実機へ書き込んだ。

## アラートのベル

GPSアプリのベルはx=152、y=2、12×12ドットとし、SDカードはx=166〜177、電池本体はx=180からとし、ベル右端163とSD左端166、SD右端177と電池左端180の間をそれぞれ2ドット空ける。選択中データセットの有効な通知設定がONなら白、越境アラート鳴動中なら黄色、OFF・利用不能・未選択では非表示とする。GPSが未測位でもONの設定は白いベルで示す。候補音の試聴では黄色へ切り替えない。確認ダイアログ中もSD・電池と同じ明るさを保つ。`AlarmBellIcon.h`の12行×uint16_t、24バイトのconstexprパターンをROMへ配置し、動的な画像確保を行わない。
