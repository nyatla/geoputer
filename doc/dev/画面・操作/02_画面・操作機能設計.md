# Geoputer 画面・操作機能設計

文書状態: Draft 0.26

対象画面: 240 × 135 px、横向き  
入力: Cardputer ADV 56キーキーボード  

## 1. 文書の目的

本書は、Geoputerの画面一覧と、共通の情報設計、操作、状態遷移および表示ルールを定義する。各画面の詳細仕様と参考画像は、画面別ディレクトリへ配置する。

Geoputerの主役は道路地図ではなく「現在地の名前」と「地名の領域」である。限られた画面を地図アプリの縮小版として使わず、現在地を短時間で理解することへ表示資源を集中する。

製品の目的と利用体験は「[Geoputer コンセプト・利用体験概要設計](../01_コンセプト・利用体験概要設計.md)」、UIが参照する動作モードとデータは「[Geoputer システム構成設計](../04_システム構成設計.md)」を参照する。

UIとApplicationの役割、受信キューおよび表示更新の通信は「[Geoputer タスク構成設計](../06_タスク構成設計.md)」に従う。

### 1.1 現在の実装範囲

Boot、Live Place、GPS Logger、Settings、Logs、Log Point、地図（Place View）を実装している。各トップ画面から1/2/3/4/0でメイン / 地図 / GPS・記録 / ログ一覧 / 設定を直接開く。LIVEのEscは画面選択MENU、他のトップ画面のEscはLIVEへ戻る操作とし、Sは消灯、GはGPS画面と共通の記録・測位操作とする。記録操作は実際のSD保存へ接続済みであり、保存済み・未保存・バッファ使用数・欠落件数とエラーを表示する。通常ファームウェアの実GPSとキー操作による記録操作の通し確認は未完了とする。

Logsでは.gps.datを省いたファイル名を選択すると基本情報のみのプロパティを開き、Enterで文字表示へ進む。2で地図表示、Pで地図リプレイを切り替える。PLAY中は上下で速度、左右で再生方向を変更する。ログを開いた後は1＝文字・2＝地図・3＝統計へ直接切り替える。[ログ閲覧](log-detail/README.md)の共通点送り・数値切替・P再生停止に従う。一覧のDは削除確認を開き、取消を初期選択として確定した削除だけをStorageへ要求する。保持中の記録ファイルは削除しない。削除中は操作と消灯を抑止し、完了後に一覧を更新する。地図は2キーから開き、境界線と現在地を表示する。＋で1/4→1/2→等倍、－で等倍→1/2→1/4へ切り替え、端では循環しない。距離・最高速度・高度範囲の全件集計はログの子画面で3を押して明示的に実行し、Rで再計算する。以下の画面一覧・状態遷移・受け入れ条件にはこれらの後続仕様を含む。通常起動は受信中・記録停止でLive Placeへ進む。消灯・記録一時停止では受信を維持し、停止操作はログを終了するがGPS受信は維持する。GPS休止処理は撤回する。詳細は[GPS Loggerの現行実装](gps-logger/README.md#5-現行実装と保存状態)と[測位記録ファイル仕様](../07_測位記録ファイル仕様.md)を参照する。

## 2. UI設計原則

### 2.1 情報の優先順位

画面全体の情報優先順位は次のとおりとする。

1. 現在地名
2. GPS・ログ・SDの動作状態
3. 現在地周辺の領域
4. 速度、進行方位、高度、衛星数
5. 緯度・経度
6. 詳細なデバッグ情報

### 2.2 操作原則

- 通常起動時はGPS受信を開始し、GPSログはSTOPPEDとする。メンテナンスではGPSを初期化しない。
- 画面消灯中の最初のキーは画面復帰にのみ使用し、設定変更には使用しない。
- 左右キーはSettingsの値編集、共通確認ダイアログの選択、ライセンス情報のソフトウェア単位ジャンプに使用する。ダイアログでは左が取消、右が実行項目となる。上下キーは一覧・メニューの選択・スクロールと、ログのPAUSE中の10点移動／PLAY中の速度変更に使用する。地図倍率は＋／－で切り替える。
- Enterは決定・OK、EscまたはDelはキャンセル・戻る。
- GPSログの一時停止・停止など、確認が必要な操作は一段階確認する。
- GPS画面は状態確認と操作をまとめる。Enterと共通Gで開始・一時停止・再開・停止を選ぶ。LIVEのEscは画面選択MENU、他のトップ画面のEscはLIVEへ戻る操作とし、数字1/2/3/4/0は各画面への直接移動とする。
- GPSログがRECORDINGの場合は、画面遷移や画面消灯で記録を止めない。
- GPSログの一時停止は位置記録だけを止める。GPSデバイスをOFFにせず、GNSS ACTIVEとLatestFix更新を維持する。明示的な停止はログを終了し、GPS受信・地名・地図の位置更新は継続する。
- データセット番号・地名用Wordbookの言語の変更は、GPSログの停止と未保存データの保存・セッション閉鎖が完了した後に限る。検証・NVS保存に成功してからReaderとキャッシュを更新し、起動中に反映する。PAUSEDは停止完了としない。起動時に選択済みデータセットを使用できない場合は原因を通知して未選択へ移し、逆ジオコーディングを停止して通常起動を継続する。

### 2.3 応答性

- 画面復帰後、100 ms程度を目標にフレームと最新状態を表示する。
- Galuchat検索は表示復帰をブロックせず、使用可能時の検索中状態を表示する。確定したデータセット異常は地名欄の原因表示を維持し、GPS更新・画面復帰では再検索しない。Live Placeの再検索では既存の地名と対応座標を保持する。キャッシュ準備状態は表示せず、SDカードアイコンをログ・地図・辞書を含む実アクセスで青く点灯する。
- 検索開始前に以前の有効な地名キャッシュがあれば、薄い表示または更新中マーク付きで先に表示する。
- キー入力に対する選択表示は、SDアクセスやGaluchat処理より優先する。
- 長い処理中も、GPSログの継続とEscによる画面離脱を可能にする。

### 共通ヘッダーと画面名通知（2026-11-01）

LIVE・MAP・GPS/LOGGER・LOGSは、左から記録状態、現在時刻、アラートのベル、SDアイコン、電池アイコン、残量数値を固定位置へ表示する。文字は8×8、アイコンは12×12を基本とし、区切り線y=16を維持する。ベルはSDの左、設定ONで白、越境通知の鳴動中で黄色、OFFで非表示とする。ログ地図だけは再生専用ヘッダーとし、PLAY/PAUSE・方向・再生倍率を表示する。現在時刻・保存時刻と地図内の再生情報行は表示せず、右側のベル・SD・電池は共通とする。

1〜4のトップ画面（LIVE・MAP・GPS/LOGGER・LOGS）へ実際に切り替えた時だけ、ヘッダー左側のx=0〜147、y=0〜15へ枠を付けずに英字の画面名を約1秒重ねる。UI言語によらず`1 LIVE`、`2 MAP`、`3 GPS / LOGGER`、`4 LOGS`をASCII 8×8・シアンでx=4、y=4に左揃えし、その間は記録状態・時刻を置き換える。右側のベル・SD・電池は常時残し、本文とフッターには重ねない。設定（0）・画面選択メニュー・ログの子画面・サブメニュー・起動チェックでは表示しない。既存オフスクリーンを使用し、追加画像バッファは確保しない。非モーダルでキーを消費せず、連続切替は最新画面名へ置き換える。同じ画面の再通知・選択移動・GPS更新では再表示しない。消灯中は表示せず、確認ダイアログと実際の鳴動操作を優先する。期限切れはUIの単調時刻で検出し、外部通知がなくても再描画して記録状態・時刻を復元する。

設定トップは「動作設定、システム設定、アラート、ストレージ操作、バージョン情報、ライセンス情報」の順とする。アラートの監視階層指定は廃止し、設定内容は[区域アラート設計](../15_区域アラート機能設計.md)に従う。

## 3. 共通ビジュアルデザイン

### 3.1 画面グリッド

画面は原則として次の3領域で構成する。

```text
┌──────────────────────────────┐ y=0
│ Status bar / 16～18 px       │
├──────────────────────────────┤
│                              │
│ Main content / 約100 px      │
│                              │
├──────────────────────────────┤
│ Context / action / 16～18 px │
└──────────────────────────────┘ y=134
```

画面によって下部領域を省略し、Main contentを広げてもよい。左右の安全余白は4 px以上とする。LIVE・地図・GPS／記録・ログ一覧・測位点のヘッダーは区切り線をy=16（上端から17 px）、8ドットの文字上端をy=4に統一する。Settingsは8ドットのタイトルを置くヘッダーを同じ17 pxとし、本文は上端27 pxから20 px間隔の4行で表示する。

### 3.2 文字サイズ

すべての画面で8×8ドットと16×16ドットの2種類を持ち、文字種ではなく表示用途でサイズを選択する。

| 表示用途 | 固定セルサイズ | 対象 |
|---|---|---|
| Live Placeの地名 | Wordbookが`ja`なら16×16（半角スペース8ドット幅）の2行。それ以外のASCIIは通常8×16の2行、長文時は8×8の最大4表示行 | 2つの論理行は維持し、ASCIIでいずれかの行が232ドットを超えたときだけ各論理行を最大2表示行に折り返す。異常表示はUI言語に従う |
| 地図の地名 | 1行目は8×8、2行目は`ja`なら16×16・それ以外のASCIIなら8×16 | 各論理行を1表示行に置き、232ドットを超えた部分は`...`で省略する。Live Placeの折返しは適用しない |
| Live Placeの速度・進行方位 | 16×16ドット | SPD / HDGの主数値、方位の°。ラベル・速度単位は8×8 |
| Live Placeの測位待ち | 16×16ドット | 地名欄の既存状態文字列`WAIT GPS FIX` |
| Settingsの主表示 | 日本語16×16 / 英語8×16 | メニュー項目、設定値、確認文、カード情報 |
| 補助表示・その他 | 8×8ドット | 画面タイトル、ライセンス本文、現在時刻、GPS状態、キーガイド、短い通知、座標、Settings以外の設定値 |

地名のフォントは選択中のWordbook言語と画面で決める。`ja`では英数字も16ドット（半角スペースのみ8ドット）とし、例えば「鷺沼2丁目1番1号」の数字も16ドットずつ送る。それ以外ではASCIIを通常8×16、非ASCIIを16ドット幅で描く。Live PlaceのASCII長文だけは8×8の折返し表示へ切り替える。Live Placeの速度・進行方位の主数値と方位の°も東雲16×16ドットとする。速度の小数点だけ元の東雲字形を使い、送り幅を8ドットへ詰める。SPD / HDGのラベルとkm/h、LAT / LON / ALT / SATの値は8×8ドットとする。GPS Loggerの操作・確認項目、Settingsの項目・設定値・確認文・カード情報は、日本語モードでは東雲16×16、英語モードではAsciiFont8x16とする。ログは選択後にプロパティを開き、Enterで文字表示、子画面の1/2/3で文字・地図・統計、Pで地図再生を切り替える。Logsのファイル名・概要数値・測位点データと、各画面のタイトル・補助表示は8×8とする。言語の選択値は日本語を16×16、Englishを8×16で表示し、文字高さを16ドットに揃える。16ドット部分は東雲の字形を使用し、英数字を8×8から2倍拡大しない。Settings画面群のタイトルとライセンス本文はASCIIの8×8ドットとする。補助表示・その他の日本語は8×8ドットとし、地名表示のフォントはUI表示言語ではなくWordbook言語で決め、ライセンスの8×8は変更しない。

日本語文字は線が潰れないビットマップのゴシック体を使用する。画面画像は240×135 pxの実寸で作成し、1画像ピクセルを1画面ドットへ対応させる。文字、罫線、アイコンは整数座標に配置し、アンチエイリアスを使用しない。拡大プレビューは最近傍法とし、実寸画像と区別する。[画像作成手順](画像作成手順.md)を参照する。

地名が表示幅を超える場合は固定サイズを維持したまま、末尾を省略する。選択中または一定時間後に横スクロールで全文を表示する。通常状態で常時流れるマーキー表示は避ける。

### 3.3 カラーパレット

| 色 | 用途 |
|---|---|
| 黒～濃紺 | 背景 |
| 白～明灰 | 通常文字 |
| シアン | 選択、現在位置、操作可能要素 |
| 緑 | REC、正常完了 |
| 黄～アンバー | PAUSE、注意 |
| 青 | SD実アクセス中 |
| 赤 | ERROR状態、GPS・SD等の問題を示す赤帯。帯内の文字は白 |
| 暗灰 | SDアクセスなし、無効操作 |

状態は色だけで伝えず、アイコンまたは短い文字を併記する。

```text
GPS●  正常Fix
GPS○  受信中・Fixなし
GPS‖  PAUSE
GPS×  UART受信なし
REC●  ログ記録中
PAUSE ログ一時停止
SDカードアイコン 青=実アクセス中、暗灰=アクセスなし
ERROR 問題の内容は赤帯の白文字
```

### 3.4 再描画

現行UIは4bit・16色パレットの全画面バッファを使用する。使用する9色のRGB565値とフォント・整数座標を維持し、UiCanvasが描画色をパレット番号へ変換する。色数だけを変更し、文字の拡大縮小や解像度の変更は行わない。画面形式は`Config.h`の`UiColorDepth`で指定し、16bitの参照描画とのピクセル比較で確認する。

- ステータスバーは1秒周期または状態変化時に更新する。
- Live Placeの速度・進行方位・高度・衛星数は新しい確定Fixで項目ごとの有効性に従って更新する。地名に対応する座標は地名検索のFixと一緒に更新する。
- 地名は検索完了時だけ更新し、毎秒検索しない。
- 状態・時計・操作の変更時に再描画を予約し、240×135の1枚のバックバッファを再構成してまとめて転送する。
- Place Viewのラスタは検索完了まで以前の画像を保持してよい。

Live Placeの上段は記録状態→現在時刻→ベル→SDカードアイコン→電池の順とし、GPS:FIXと正常時SD OKを常設しない。住所は都道府県・市区町村と町名以降の2行とし、その下を左右パネルに分ける。左に16ドットの速度SPD・進行方位HDG、右に8ドットのLAT・LON・ALT・SATを置く。HDOPはメイン表示から外し、GPS取得・ログ記録には残す。RG表示は廃止し、アラート設定ONは白いベル、鳴動中は黄色いベルで示す。SDだけ短いI/Oを最低150ms表示する。配置の正本は[Live Place画面レイアウト仕様](live-place/レイアウト仕様.md)とする。

## 4. ナビゲーション構造

Esc（Fnなしの物理Escを含む）はLIVEから画面選択MENUを開き、他のトップ画面ではLIVEへ戻る。MENUは各画面への階層入口であり、数字は同じ行き先へのショートカットとする。同じ画面の数字を押しても画面を作り直さない。下位階層・値編集中・確認中・削除実行中は数字による移動を行わない。BootのEsc長押し・押下は従来どおりメンテナンスへ入る。USBとメンテナンスでは通常のMENUとショートカットを無効とする。

```text
ESC MENU
├ 1 メイン（Live Place）
├ 2 地図（Place View）
├ 3 GPS・記録（GPS Logger）
├ 4 ログ一覧（Logs）
│ └ Log Point（文字表示、2で地図、Pで再生）
└ 0 設定（Settings）
   ├ 動作設定
   ├ システム設定
   ├ アラート
   ├ ストレージ操作
   ├ バージョン情報
   └ ライセンス情報
```

| キー | 動作 |
|---|---|
| Esc（Fn不要） | LIVEでMENU、他のトップではLIVEへ戻る。下位では取消・一段戻る |
| `1` / `2` / `3` / `4` / `0` | メイン / 地図 / GPS・記録 / ログ一覧 / 設定へ直接移動 |
| `S` | 表示を消灯する。GPS・記録は継続し、復帰時は元の画面を維持する |
| `G` | GPS・記録の共通操作ダイアログを開く。子画面からも使用できる |
| `↑` / `↓`、`;` / `.` | メニュー・一覧の選択。地図では等倍・1/2・1/4の切替 |
| `←` / `→`、`,` / `/` | 設定値の編集、確認ダイアログの選択、ライセンスのソフトウェア単位移動 |
| `D` | ログ一覧で削除確認を開く |
| Enter | 選択・決定。GPS画面ではGと同じ操作ダイアログを開く |
| Del | 取消・一段戻る。トップではメインへ戻る |

数字・S・GはFn併用も同じ意味とする。従来のP一時停止は廃止する。画面消灯中の最初のキーは復帰のみとし、同時にショートカットを実行しない。確認ダイアログが開いている間はS・G・数字も受け付けない。上下の長押しは400ms後から100ms間隔で反復する。

最下段は[共通キー操作](共通キー操作.md)を正本とする。ESCを含むグローバル、数値、ローカルの順に詰め、グループ間だけ1セル空ける。ESCはFlash上の枠付き24×12マークで表示し、Enterに機能がある場所では12×12の枠付き改行キー風マークをローカル操作に表示する。Delは暗黙として表示しない。数字はトップ画面の選択と、ログ子画面の1＝文字・2＝地図・3＝統計に使う。それ以外の子画面には置かない。LIVEのEscは画面選択MENU、他のトップのEsc/DelはLIVEへ戻る。子画面と編集・確認では戻る・取消とし、LIVEのDelは無効とする。

GPS操作は[GPS Logger](gps-logger/README.md)に従う。GPS操作ダイアログに取消項目は置かず、Esc / Delで取消する。開始待ち・記録中は一時停止、一時停止中は再開、停止中は開始を初期選択にし、左右で操作を選んでEnterで確定する。停止はログの保存・終了を要求し、一時停止はセッションを維持する。どちらもGPS受信を継続する。

## 5. 画面消灯と復帰

### 5.1 消灯

設定された時間キー操作がなければ、UIが最終入力時刻を含む消灯要求を保持し、UiContentChangedを通知する。AppがGetUiContentで現在内容を同期取得し、要求が有効であることを確認する。

1. UIが未確定の設定編集を取消または確認対象として扱う。
2. AppがUpdateUiContentでBACKGROUND_MODEと処理済みaction_idを指定する。
3. UIが指定を保持して同期結果を返し、タスク内でバックライトを消灯する。

GPSログがRECORDINGの場合は、GNSS ACTIVE、LatestFix更新、RAMログ追加および定期SD保存を継続する。PAUSEDの場合は記録だけを停止してGNSS ACTIVEを維持する。STOPPEDでもGPS受信を継続する。

### 5.2 復帰

画面消灯中の最初のキーは、UIが復帰操作として保持してUiContentChangedを通知する。AppはGetUiContentで復帰操作を同期取得する。

1. AppがUpdateUiContentでVIEW_MODEと処理済みaction_idを指定し、消灯前の画面を維持する。
2. UIが指定を保持して同期結果を返し、バックライトと画面を非同期に更新する。
3. AppがGNSS・GPSログ・SDの状態を集約し、UpdateUiContentで表示用データを渡す。
4. GPSは連続受信しており、復帰時のGNSS制御は行わない。
5. 直前の有効なFixと検索結果は前回位置として表示できる。
6. 新しい有効Fixを得たらAppがStorageへ検索要求を通知する。
7. 結果通知をAppが受け、UpdateUiContentで地名を渡す。UIが描画する。

復帰を発生させたキーは画面内操作へ引き継がない。処理済みの復帰操作と画面指定がUIへ反映されるまで次の確定操作を抑制する。

## 7. 通知とダイアログ

### 7.1 トースト通知

処理結果は画面下部へ2～3秒表示する。

```text
Log flushed
Settings saved
Galuchat data unavailable
```

トーストはGPS状態やREC表示を恒久的に隠さない。

### 7.2 確認ダイアログが必要な操作

- ログ削除
- Geoputerの設定初期化
- SDカードのFAT32フォーマット（ログ・GISデータを含む全データ消去）
- GPSログの一時停止
- GPSログの停止

選択を伴う確認はすべて[共通確認ダイアログ](共通確認ダイアログ.md)を使う。上記5操作とUSBモードへの切替・終了に適用する。背景を暗く残した中央ウインドウに上下1ドットの白線を引き、取消と操作を横並びにする。初期選択は取消、左で取消・右で実行項目を選択、Enterで確定、Esc / Delで取消とし、上下キーや画面ショートカットは受け付けない。

### 7.3 エラーバナー

SD書込み失敗・RAM満杯・GPS受信断等は、Live Place本文下部の赤地・白文字の帯に内容を表示し、トーストだけで消さない。最上段のERRORは問題の存在を示し、Appの記録要求・停止・一時停止状態とは分ける。SDアイコンの色をエラー表示に代用しない。

Storageの同期受付エラーは戻り値、受付後の実保存エラーはStorageError通知からAppが把握する。Appがエラー種別・未保存件数・バッファ使用数と容量・欠落件数を集約し、先の同期結果を取得してからUpdateUiContentでUIへ渡す。UIは受け取った状態を自タスク内で描画する。

Live Placeでは赤帯に、GPS Loggerでは状態欄と件数表示に反映する。書込み・flush失敗はSD ERROR、RAM満杯の受付失敗はBUFFER FULLとして区別し、バッファ容量は64件とする。受付失敗だけで欠落したと表示しない。画面切替やGPS更新で保存エラーを消去せず、Appが対応する処理・媒体の回復を確認した状態を渡したときに更新する。


### 7.4 データセット異常の共通表示

使用中のデータセットの欠落・構成／形式不正・文字コード未対応・上限超過・メモリ不足・読出し失敗は、起動停止にせずLive Placeの地名2行に統一する。日本語・英語の固定文言、優先順位、逆ジオコーディング停止と明示操作による再検証は[データセットメタデータ仕様8.3〜8.4節](../08_データセットメタデータ仕様.md#83-起動時の復元とエラー)に従う。データセットだけの異常を赤帯・全面警告へ重複させず、Fix喪失で地名欄の原因を上書きしない。未選択候補の検証失敗はSettings内で表示して適用を拒否し、使用中データのエラーにしない。

この変更はコードと新しい日英の地名欄エラー画像へ反映済み。[検証結果](../検証/データセット異常時の起動継続検証.md)でホスト・描画・実機の確認範囲を区別する。

### 7.5 機能の利用条件と制約

[システム構成設計7節](../04_システム構成設計.md#7-エラー状態と機能の利用条件)を共通の判定基準とする。GPS Fixなしでは現在位置・地名の更新と新しい測位点の追加を制約し、設定やSD上の既存ログ操作を禁止しない。ログ開始・再開の受付と有効Fix待ちは分ける。SD利用不可でもGPS表示・NVS設定操作は継続し、データセット異常だけなら逆ジオコーディング以外の機能を維持する。

画面を開けることと、その画面の操作が成功することは別とする。必要条件を満たさない操作は理由を表示し、設定・復旧操作や元画面へ戻る経路を残す。SD書込みだけの失敗を読出し不能に拡大せず、保存済み・未保存・記録状態を別に表示する。バージョン・ライセンス情報はGPS Fix・SD・NVS保存なしで閲覧可能とする。エクスポートはUSBモード内でSDの所有権を取得して行う既存仕様を維持する。

## 8. 状態遷移

```text
                     key
        ┌────────────────────────────┐
        │                            v
┌────────────────┐            ┌──────────────┐
│BACKGROUND_MODE │<─ timeout ─│  VIEW_MODE   │
│LCD OFF         │            │  LCD ON      │
└────────────────┘            └──────────────┘
```

画面モードとGNSS・GPSログ状態は独立して遷移する。

```text
Power on: GPS受信開始 / LOG STOPPED

GPS Logger Start:  受信準備確認 → LOG STARTING → 新しい有効Fix → LOG RECORDING
GPS画面 / G Pause: 記録追加停止 → 保存要求の同期受付 → LOG PAUSED（GPS受信維持）
GPS Logger Resume: 新しい有効Fix → LOG RECORDING
GPS Logger Stop:   記録追加停止 → 保存・終了要求の同期受付 → LOG STOPPED

LOG STOPPED / PAUSED / 表示消灯 → GPS受信は継続
```

Galuchat検索は動作モードではなく、VIEW_MODE内の短命なジョブとして扱う。

```text
IDLE → QUEUED → READING → COMPLETE
                    └──→ ERROR
          Esc/画面遷移 → CANCEL_REQUESTED
```

Readerが安全に中断できない場合、画面表示だけを離脱し、現在の短い読込単位が終了した時点でジョブを破棄する。

## 9. UIが参照するモデルと操作内容

Appは表示する画面、表示モード、確定した設定、GPS・ログ・Storageなどの業務状態を所有する。UIは画面内の選択項目、ダイアログ操作、編集途中の値を所有する。

AppはGPS・Storageの通知を一度受信して表示データへ集約し、SetUiScreen / UpdateUiContentの同期メッセージでUIへ渡す。同期操作は指定・データ保持までとし、実際の描画とバックライト更新はUIタスク内で非同期に行う。表示更新で選択・編集状態を初期化しない。

```cpp
struct UIStatus {
    GPSStatus gps;
    LogStatus log;
    StorageStatus storage;
    GaluchatStatus galuchat;
    BatteryStatus battery;
};
```

ユーザー操作でUI内容が変わるとUiContentChangedをAppへ通知する。AppはGetUiContentで現在の選択・編集値・確定操作を同期取得し、業務操作を検証・実行する。

```text
UIタスク内でユーザー操作
  ↓
UiContentChanged → App
  ↓
App → GetUiContent（同期） → 操作内容取得
  ↓
AppがGPS・Storageの操作や画面遷移を判断
  ↓
App → SetUiScreen / UpdateUiContent（同期）
  ↓
UIが処理済み操作を反映し、非同期に描画
```

開始・停止・設定確定などの未処理操作はUIに1件保持し、Appの処理済みaction_idが反映されるまで次の確定操作で上書きしない。表示データ受信・再描画はUiContentChangedを発行する理由にしない。

同期結果取得のタイムアウトでも同じ要求の結果取得を続ける。通信と操作内容の詳細はタスク構成設計4.6節に従う。

## 10. UI受け入れ条件

- 電源投入時はGPS受信を開始し、GPSログSTOPPEDが表示される。
- 表示指定とデータ受渡しの同期完了後に、UIタスクが非同期で描画する。
- UiContentChangedを契機に操作内容を同期取得し、確定操作を1件保持して処理する。
- GPS Logger画面からGPSログを開始・再開・停止できる。
- GPS画面とGから一時停止し、記録だけを止めてGPS受信を維持する。
- MENUと1/2/3/4/0が同じ画面へ移動し、下位階層ではEsc / Delで一段戻れる。
- GPSログ開始時にGNSSがACTIVEとなり、有効Fix取得後にRECORDINGへ移行する。
- GPSログがRECORDINGの場合は画面消灯中も記録が継続する。
- GPSログがPAUSEDの場合は画面消灯中もGNSS ACTIVEを維持する。STOPPEDでもGPS受信を継続する。
- 任意キーでLive Placeへ復帰する。
- 復帰キーが設定変更として処理されない。
- 有効Fixがあれば地名検索中表示を経て地名が表示される。
- Fixなし、Galuchatデータなし、SDエラーを互いに区別できる。
- 左右キーはSettingsの値編集、共通確認ダイアログ、ライセンス情報のソフトウェア単位ジャンプで動作する。Escはキャンセル、Enterは決定として動作する。
- Place Viewで現在位置、現在領域、周辺領域および縮尺を識別できる。
- GPS Logger画面の表示中はGaluchat検索を行わない。
- GPS接続はシステム設定内のMesh Kit固定・読取専用とし、外付けGPSは未実装であることを示す。
- Settingsの5メニューを子画面で操作し、初期化はシステム設定から開く。Escで一つ上の画面へ戻れる。
- SDが利用できなくてもNVS設定を読込み・保存でき、NVS保存失敗とSDエラーを区別できる。
- 設定初期化とSDフォーマットは確認後だけ実行し、互いの保存媒体のデータを変更しない。
- SD未挿入でもOSS・フォントのライセンス本文をスクロールして閲覧できる。
- 15秒無操作の初期設定で画面が消灯する。
- 長い一覧処理またはGaluchat処理中もGPSログを失わない。

## USBストレージの起動モード

起動前にNVSのフラグを読み、GPSロガーを含む通常起動とUSBストレージ起動を分ける。設定のトップ階層に「システム設定」を置く。モード候補の編集後、「保存して再起動」の確認からフラグ保存・再起動を要求する。記録停止完了を必要とし、GPS接続は同じ子画面へ配置する。USB起動ではGPS・GISを開始しない。PC公開中は端末側のSDファイル操作を行わない。USB専用画面から共通終了ダイアログを開き、PCでの保存完了後、終了の確定でSD同期・公開停止・GPSロガーのフラグ保存・再起動を行う。PC公開中でも終了は選択可能とする。USB画面と終了確認は自動消灯しない。

USB起動時は「ログを書き出す」「ロガーへ戻る」のメニューを表示する。書き出しはログ選択→GPX・KML・CSVの形式選択→変換→完了の順とし、PC公開中だけ安全な取り外し案内を挟む。未接続・安全な取り外し済みは案内を省略する。USBモード内で公開を止めてStorageが変換し、完了後にSDを再公開する。出力先と命名は[ログエクスポート仕様](../10_ログエクスポート仕様.md)、画面は[エクスポート画面](usb-storage/export-proposal/README.md)を正本とする。変換中は取消・モード終了を受け付けず、同名出力を上書きしない。

画面仕様は[USBストレージ](usb-storage/README.md)、起動・排他・保存の契約は[起動モード・USBストレージ仕様](../09_起動モード・USBストレージ仕様.md)に従う。

メンテナンスではSettingsを使用し、自動の位置検索・記録開始・画面消灯を抑止する。入口のEsc / Delは通常画面へ直接戻さず、取消を初期選択とする再起動確認を開く。[Bootの復旧経路](boot/README.md#5-escによるメンテナンス起動)に従う。

全画面のSDアクセス表示は[共通ステータスアイコン](共通ステータスアイコン.md)に統一する。
