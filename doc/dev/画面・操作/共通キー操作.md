# 共通キー操作と最下段の表示

## 1. キーの分類

最下段は「グローバルショートカット → 数値による画面選択 → ローカル操作」の順に左から詰めて表示する。画面ごとに固定の空き枠を予約しない。ESCは24×12、Enterは12×12ピクセルの枠付きマークとし、その他のキーは8×8セルを1個使い、同じグループ内に空白セルを挿入しない。存在するグループの間だけ8ピクセルの空白セルを1個挿入する。空のグループ・前後の空白・連続した空白は表示しない。

ESCはグローバル操作の先頭とする。[24×12のESCキーキャップ](escape-icon.png)をFlash上の1ビット固定パターンから直接描く。枠内の小さなESC文字もパターンの一部とし、隣のS/Gと区別できるようにする。本書ではこれを⎋と表記する。Enterに機能がある場所では、ローカル操作の先頭に[12×12の枠付き改行キー風マーク](enter-icon.png)を表示し、本書では↵と表記する。Delは戻る・取消の暗黙キーとして表示しない。

先頭位置はx=4。通常文字と方向矢印はy=124・8ピクセル送りとする。ESCは24ピクセル送り、Enterは12ピクセル送りとし、両者の枠はy=122〜133へ置く。14ピクセルのフッター（y=121〜134）に上下1ピクセルの余白を残し、本文や区切り線を侵さない。LIVEはESCがx=4〜27、Sが28、Gが36、空白が44、数値12340が52〜84となる。ローカル操作があるトップ画面では空白をx=92へ置き、操作キーをx=100から続ける。右余白は4ピクセル以上とする。

割当がないキーは省略する。割当はあるが状態・端点・処理中の制約で使えないキーはグレーにする。ESC・Enterと通常キーは操作可能時に白、現在画面の数値だけをシアンとする。上下左右は8×8セルのビットマップで示す。

## 2. ESCとDel

| 状態 | ESC | Del |
|---|---|---|
| LIVE | 画面選択MENUを開く | 無効 |
| MENU | LIVEへ戻る | ESCと同じ |
| 地図・GPS／記録・ログ一覧・設定トップ | LIVEへ戻る | ESCと同じ |
| 子画面 | 親へ戻る | ESCと同じ |
| 値編集 | 未確定の変更を取り消す | ESCと同じ |
| 確認・操作ダイアログ | 操作を取り消して閉じる | ESCと同じ |
| Boot | メンテナンスを要求 | 無効 |
| メンテナンス設定トップ | 通常モードへの再起動確認 | ESCと同じ |
| USB | そのページの戻る・取消・終了確認 | ESCと同じ |

物理EscはFnなしでも使用できる。起動時のEsc保持によるメンテナンスと、消灯中の最初のキーを復帰専用にする仕様は維持する。画面選択MENUは廃止せず、LIVEのESCと数値による画面選択を併用する。

## 3. 数値とグローバル操作

数値は1＝LIVE、2＝地図、3＝GPS・記録、4＝ログ一覧、0＝設定。MENUと各トップ画面で直接切り替える。同じ画面の数値は表示を作り直さない。ログを開いた後の子画面（プロパティ・文字・地図・統計）では、数値グループを1＝文字、2＝地図、3＝統計へ切り替える。ここではトップ画面の1/2/3として扱わず、0/4も無効とする。その他の子画面・値編集・ダイアログ・Boot・USB・メンテナンスには数値グループを表示せず、画面切替も受け付けない。

Sは消灯、GはGPS・記録操作ダイアログ。通常モードでは設定の子画面や値編集中、ログ閲覧中でも有効とする。確認ダイアログ中・Boot・USB・メンテナンスではS/Gを表示しない。消灯はGPS受信・ログ記録を止めないが、ログのリプレイは一時停止する。リプレイ中にGを開いた場合も再生を一時停止する。

TABは数値グループがある画面で、表示されている数値の順に次の有効な画面へ切り替える。トップ画面は1→2→3→4→0→1、ログの子画面は1（文字）→2（地図）→3（統計）→1。現在の画面を飛ばし、利用不能な切替先も飛ばす。MENUとログプロパティは対応する現在番号がないため、最初の有効な番号から始める。次の候補がない場合や要求の応答待ち・読出し中は何もしない。数値グループがない画面、確認ダイアログ、USB、Boot、メンテナンスでは切替を行わない。消灯中の最初のTABは復帰だけに使う。TABは暗黙の操作とし、フッターにマークや文字を追加しない。Vの表示切替は廃止する。

## 4. 画面ごとのキー一覧

以下の空白はグループの区切りであり、グループ内に説明語や空白を加えない。状態によって色は変わる。

| 画面・状態 | 最下段 |
|---|---|
| LIVE | ⎋SG 12340 |
| 地図 | ⎋SG 12340 +- |
| GPS・記録 | ⎋SG 12340 ↵ |
| ログ一覧 | ⎋SG 12340 ↵D↑↓ |
| MENU・設定トップ | ⎋SG 12340 ↵↑↓ |
| ログプロパティ | ⎋SG 123 ↵ |
| ログ統計 | ⎋SG 123 R |
| ログ文字表示 | ⎋SG 123 BE←→↑↓ |
| ログ地図・リプレイ | ⎋SG 123 BE+-P←→↑↓ |
| 設定の一覧・データセット一覧 | ⎋SG ↵↑↓ |
| 設定値・地名言語・動作モードの編集 | ⎋SG ↵←→ |
| ライセンス | ⎋SG ←→↑↓ |
| バージョン・カード情報・初期化・索引結果 | ⎋SG ↵ |
| 確認・GPS操作のダイアログ | ⎋ ↵←→ |
| Boot | ⎋（起動完了後は ⎋ ↵） |
| メンテナンス | 上記の設定用キーからSGと数値を除く |
| USBトップ・ファイル一覧・形式一覧 | ⎋ ↵↑↓ |
| USB取り外し待ち・完了・エラー | ⎋ ↵ |
| USB準備中・書き出し中 | 空欄 |

データセットの適用・保守処理中はESCをグレーにし、処理が終わるまで戻らない。USBの準備・書き出し中は戻る操作自体を割り当てない。操作要求の応答待ちとモード切替中は入力を抑止し、残るキー案内をグレーにする。最下段にWAIT等の操作説明を上書きせず、状態は本文の進捗・表示で伝える。

Enterの割当がないLIVE・通常地図・測位点・統計・ライセンスには↵を表示しない。データセット詳細の情報行やシステム設定の表示専用行も省略する。機能がある行の読出し中、選択不可、空のログプロパティ、実行条件未達では↵をグレーにする。確認ダイアログでは現在の選択肢を確定できる場合だけ点灯する。

## 5. ローカル操作

上下は一覧の選択・スクロール。左右は値の変更・ダイアログ選択。物理キーの別名は上＝;、下＝.、左＝,、右＝/。ライセンスでは＜＞も前後のソフトウェア先頭への移動に使用する。

ログ一覧のDは削除確認。プロパティのEnterは測位点の文字表示へ進む。プロパティ・文字・地図・統計の1/2/3は、それぞれ文字・地図・統計への直接切替。統計のRは再集計。Mによる表示選択ダイアログは設けない。現在の表示に対応する数字はシアンにし、同じ数字を押しても画面・再生状態を変更しない。読出し・集計中や前提条件を満たさない表示先はグレーにして受け付けない。文字／地図間は現在点を維持し、表示種類が変わる場合だけ再生を一時停止する。統計からも同じ点へ戻れる。測位点のPAUSE・文字表示は左右1点、上下10点、B/Eで先頭／末尾、1/2で文字／地図を切り替える。PLAY中は上で加速、下で減速、左で逆再生、右で順再生を選び、点送りや一時停止は行わない。地図は＋（=でも可）と－で倍率を切り替え、Pでリプレイの再生／一時停止を切り替える。B/Eの移動と数値による表示切替は再生を一時停止する。PLAY中の上下は速度の上下限、左右は現在選択中の方向に対応するキーをグレー表示し、PAUSE中は点の先頭・末尾に応じて矢印をグレーにする。

確認ダイアログの選択は左右だけを使う。Enterで決定し、ESC/Delで取り消す。上下・数値・S/Gは受け付けない。実行不能な項目はグレーにして選択・実行を拒否する。

## 6. 実装と検証

UiModel::shortcutGuideが小さな固定長の値としてキー列を構築し、UiRenderer::presentがすべての画面・ダイアログに同じ描画を適用する。配列は描画中の局所スタックに置き、画面ごとの常設データやヒープ領域を増やさない。EscapeIcon.hは48バイト、EnterIcon.hは24バイトのパターンを持ち、ROMに置く。キーごとの幅をUiShortcutGuide::pixelWidthで合計し、画面内に収める。R等のローカルキーはKeyBindings.hの一覧をUiTaskと試験で共用し、キー定義だけが残って実機へ届かない状態を防ぐ。

キー遷移・グループ順はrun_native.py、全画面群・言語・4/16ビット色・ダイアログの画素と余白はrun_status_icons.pyで確認する。画面画像はtools/render_*.pyで実装から生成する。

## 通知音の消音

区域アラート・試聴の発音中は、最初のキーを消音専用とし、表示中の画面操作・ダイアログ選択・数値切替を実行しない。フッターは白いESCマークだけを表示し、他のキーでも消音できる。消灯中なら消音と同時に復帰する。消音後は元の画面・編集状態を維持し、境界往復の抑制状態を解除しない。最大発音時間は60秒とする。
