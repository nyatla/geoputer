# Geoputer データセットメタデータ仕様

文書状態: 仕様1.3（ファイル形式バージョン1、読込み・切替を実装、実機検証前）
更新日: 2026-10-17  
対象: microSD上のGaluchatデータセットに付属するメタデータ

## 1. 目的と適用範囲

本書は、データセットのタイトル、短い説明、使用するGLCおよび言語別Wordbookの対応を定義する。番号ディレクトリごとに小さなテキストファイルを配置し、固定長の行バッファで順次処理できる形式とする。JSONや汎用INIの全機能は使用しない。

解像度、格納範囲、チャンク数はGLCを正本とし、本メタデータへ重複して記載しない。Wordbookの文字コードはWordbook内部のメタデータから判定する。

本書はファイル形式と、データセットの選択・保存・再起動・起動失敗の条件を定義する。タスク通信は同期で受付・非同期で結果通知するDatasetOperationを使用し、NVS保存は設定レコードの形式バージョン3を使用する。タスクの責務は[タスク構成設計](06_タスク構成設計.md)、配置と利用条件は[システム構成設計](04_システム構成設計.md#6-galuchatデータ)に従う。

## 2. 配置とデータセットの単位

SDカード直下の`/dataset/01/`、`/dataset/02/`等の番号ディレクトリを、それぞれ独立したデータセットとする。ディレクトリ名は`01`〜`99`のASCII数字2桁に限定し、`00`、1桁、3桁以上や数字以外を含むディレクトリは候補にしない。各ディレクトリ直下にメタデータ`dataset.ini`を1個、使用する共通のGLCを1個、Wordbookを言語ごとに配置する。

```text
/dataset/
├ 01/
│  ├ dataset.ini
│  ├ municipality.glc
│  ├ municipality-ja.giswordbook
│  └ municipality-en.giswordbook
└ 02/
   ├ dataset.ini
   ├ town.glc
   └ town-ja.giswordbook
```

パスはSDカード内の表記とし、本体のマウント先を含める場合は`/sd/dataset/01/dataset.ini`となる。識別にはディレクトリ名を使い、翻訳や編集によって変わるタイトルを識別子として使用しない。ディレクトリ番号をINI内へ重複して記載しない。

地図とWordbookのファイル名はINIで明示する。拡張子に一致するファイルが別に存在しても、指定されていないファイルを自動選択しない。

## 3. テキストと読取り規則

| 項目 | 規則 |
|---|---|
| 文字コード | UTF-8。BOMなしを基本とし、先頭のUTF-8 BOMは許容する |
| 改行 | LFまたはCRLF。最終行の改行は省略できる |
| 行の長さ | ファイル先頭のBOMと改行を除き最大255バイト。UTF-8の文字数ではなくバイト数で数える |
| 空白 | 行頭・行末、およびキー・値の前後のASCII空白とタブを除去する。値の内部の空白は保持する |
| 空行 | 無視する |
| コメント | 行頭の空白除去後に`#`で始まる行を無視する。行末コメントは扱わない |
| セクション | `[dataset]`または`[言語識別子]`とする。閉じ括弧の後には空白以外を置かない |
| 項目 | 最初の`=`でキーと値を分ける。以後の`=`は値の一部とする |
| 引用・エスケープ | 解釈しない。引用符やバックスラッシュは文字として扱う |
| 複数行の値 | 使用しない。タイトルと説明も各1行とする |
| 大文字・小文字 | セクション名とキー名は区別し、本書の小文字表記を使用する |

最初のセクションより前に項目を置かない。同じセクション名を複数回宣言せず、同一セクションの定義済みキーを重複させない。行長超過、UTF-8の不正なバイト列、NUL、構文に合わない行は不正なメタデータとして扱う。行を切り詰めて解釈しない。

形式バージョン1における未知のキーは無視する。セクションは共通情報と言語情報だけを使用し、任意の独自セクションは設けない。既知項目の意味を変更する場合は形式バージョンを変更する。

読取りは1行ずつ行い、一覧や選択中の表示に必要な項目だけを保持する。全ファイルの読込みや、全言語を動的なツリーへ展開することを前提にしない。行の格納には終端NULを含め256バイトを用意し、改行の処理で行長上限を超えて格納しない。実装時の行長上限は、他の容量設定と同様に`application/Config.h`へ集約する。

## 4. セクションと項目

### 4.1 共通情報 `[dataset]`

| キー | 必須 | 内容 |
|---|---|---|
| `version` | 必須 | 本形式のバージョン。値は`1`とする |
| `map` | 必須 | 使用するGLCのファイル名。拡張子は`.glc`とする |
| `default_language` | 必須 | データセットの既定言語。対応する言語セクションが存在すること |

各値は空にしない。共通情報セクションは1個とし、言語セクションとの記載順序は問わない。

### 4.2 言語情報 `[ja]`、`[en]`等

言語識別子はASCII小文字の英字から始め、小文字英数字のまとまりをハイフンで区切る。`ja`、`en`、`en-us`等を使用できる。空の識別子、先頭・末尾のハイフン、連続するハイフンは使用しない。言語識別子は最大31バイトとし、終端NULを含む32バイトの固定領域で扱う。`dataset`は共通情報のために予約する。

| キー | 必須 | 内容 |
|---|---|---|
| `title` | 必須 | その言語で表示する短いデータセット名。空にしない |
| `description` | 任意 | その言語で表示する短い説明。省略または空の場合は説明なしとする |
| `wordbook` | 必須 | その言語のWordbookのファイル名。拡張子は`.giswordbook`とし、空にしない |

言語セクションは1個以上とする。言語識別子は地名の言語を表し、文字コードを表さない。各言語のWordbookはUTF-8で、共通GLCの区域コードに対応する辞書であることを配布物の条件とする。言語の一致だけで区域コードの対応が保証されたとは扱わない。

`map`と`wordbook`は同じディレクトリ直下のファイル名だけを指定する。絶対パス、サブディレクトリ、`/`・`\`・`:`を含む指定、`.`と`..`は認めない。別の番号ディレクトリのファイルを参照しない。

## 5. 表示と言語の扱い

一覧はディレクトリ番号とタイトルを表示し、説明は詳細表示用に使用する。タイトル・説明はUIの表示言語に一致するセクションを使用し、該当セクションがない場合は`default_language`のセクションを使用する。画面に収まらない文字列はUTF-8の文字境界を保って表示側で省略し、保存内容自体は切り詰めない。

UIの表示言語と、地名取得に使うWordbookの言語は別の情報として扱う。日本語UIで英語地名を表示する組合せも表現できる。データセットを初めて選択した場合は`default_language`を地名用言語の初期値とし、詳細画面で収録されている別の言語へ変更できる。UIの表示言語を変更するだけでは、選択済みのWordbookを変更しない。選択したディレクトリ番号と言語識別子を一組としてNVSへ保存する。

本形式による言語の記載は、端末にその言語のフォントが実装されていることを保証しない。描画可能な文字とレイアウトは画面共通仕様に従う。

## 6. GLC・Wordbookとの役割分担と検証

一覧取得ではINIを読み、全候補のGLC本文や索引を読み込まない。説明とWordbookの対応は必要時にINIを読み直して取得できる。GLCからの情報取得・利用条件の検証は対象の選択時に行う。INIの読取り成功だけを、使用可能判定としない。

| 情報 | 正本と取得方法 |
|---|---|
| タイトル・説明・言語別ファイルの対応 | `dataset.ini` |
| 経度・緯度方向の解像度 | GLCの`unit_inv_x`・`unit_inv_y`。1セルの角度幅はそれぞれ逆数で表す |
| 格納範囲 | GLCの各チャンクの位置・幅・高さから求める。全体の外接矩形にはデータのない隙間を含み得る |
| チャンク数 | GLCから取得し、最大1500チャンクの利用条件を適用する |
| Wordbookの文字コード | Wordbook内部の`token_encoding`、未指定または空の場合は`text_encoding`。`utf8`または`utf-8`のみを大文字・小文字を区別せず受け付ける |

解像度は角度単位であり、固定のメートル値とは扱わない。INIへ範囲・解像度・チャンク数・文字コードを追記しても、それらを本体データの代わりに使用しない。

INI・Wordbook・タスク間メッセージ・UIの文字列はUTF-8に統一し、端末内で文字コードを変換しない。SJIS（CP932）やUTF-16、文字コード未指定のWordbookは文字コード未対応として扱う。UTF-8を宣言したWordbookの不正バイト列は地名読出し時に検出し、地名キャッシュに登録しない。ヘッダー確認時に全地名を走査することは要求しない。

既存のSJIS版Wordbookを使用していたSDカードは、同じGLCに対応するUTF-8版Wordbookを配置し、INIの`wordbook`をそのファイル名に更新する。ファイル名や文字コード宣言だけの変更ではデータ本体を変換できない。GLC・INIの形式バージョンとNVS設定レコードの形式は変更しない。

適用前には指定したGLCと使用対象のWordbookの存在、対応するファイル形式、Wordbookの文字コード、およびGLCのチャンク上限を検証する。指定ファイルが不足している場合に、別のファイルを拡張子で検索して代用しない。

## 7. 異常時の扱いと現行実装との区別

| 状態 | 扱い |
|---|---|
| `dataset.ini`が存在しない、または読み取れない | メタデータを利用できないデータセットとして扱う |
| 構文不正、行長超過、必須項目の不足、セクション・定義済みキーの重複 | 不正なメタデータとして扱う |
| `version`が`1`以外 | 未対応のメタデータ形式として扱う |
| 既定言語のセクションが存在しない | 不正なメタデータとして扱う |
| 指定したGLC・使用対象のWordbookが存在しない | 対象ファイル不足として扱う |
| GLC・Wordbookの形式不正、文字コード未対応、読出し失敗 | 本体データの検証エラーとして扱う |
| GLCが1501チャンク以上 | チャンク上限超過として扱い、地図本文の検索へ進まない |

不正なデータセットを新たな選択値として適用・保存しない。検証失敗時は以前の有効な選択と保存値を維持し、再起動しない。起動時に保存済みの選択先が見つからない場合は、8節の起動エラーとして扱い、通常起動を継続しない。

現行ソースは本書のメタデータ読取り、一覧・詳細・言語選択、停止完了条件の確認、NVS保存後の再起動、選択先欠落時の起動停止を実装する。実機への書込み・操作確認は未実施である。実装と検証範囲は[データセット切替実装検証](検証/データセット切替実装検証.md)を参照する。

## 8. 選択・保存・再起動

### 8.1 選択画面

動作設定の「データセット」から番号・タイトルの一覧を開く。上下キーで選択し、Enterで詳細を開く。詳細にはタイトル、説明、GLCから取得した解像度・格納範囲・チャンク数、地名用Wordbookの言語を表示する。地名用言語はUIの表示言語と独立して選択できる。Esc / Delで戻る操作や候補の変更だけでは、使用中のデータとNVSを変更しない。

### 8.2 変更の前提と適用

データセットまたは地名用Wordbookの言語を変更して適用する前に、GPSログの停止が完了していなければならない。一時停止のPAUSEDは停止完了として扱わない。STOPPEDに加え、未保存レコードの保存、保持中の採用点の処理、セッションの閉鎖まで完了していることをAppが確認する。変更のために記録を自動停止せず、条件を満たさなければGPS Loggerで停止するよう表示する。

適用操作は「適用して再起動」として示す。Appが停止完了条件を再確認し、候補のGLCと使用対象のWordbookを検証した後、番号と言語の組をNVSへ保存する。保存要求の受付ではなく、実際の保存成功を確認してから再起動する。保存失敗ではエラーを表示し、再起動や新しいデータの適用を行わない。現在の番号と言語の組に変更がなければ再起動しない。

適用の受付後から検証・保存・再起動までの間は、ログの開始・再開を受け付けない。検証または保存に失敗して適用を取り消した後は、旧データセットのまま通常の操作へ戻す。

新しいデータセットとWordbookは再起動後にオープンする。実行中のReaderやキャッシュを新しいデータへ差し替える方式は採用せず、旧矩形キャッシュ・地名キャッシュを再起動後へ持ち越さない。

### 8.3 起動時の復元とエラー

起動時はNVSから番号と言語の組を復元する。選択値が未保存の場合は番号`01`と、そのINIの`default_language`を初期選択とする。先行版の固定候補値をディレクトリ番号として流用せず、旧形式からの移行時もこの初期選択を使用する。

保存された番号ディレクトリ、`dataset.ini`、指定GLC、選択した言語のセクションまたはWordbookが見つからない場合は、「データセットが見つかりません」（英語: `Dataset not found`）を表示して起動エラー画面で停止する。SD未挿入等で選択先を発見できない場合も同様とする。別番号や別言語、拡張子検索への自動切替を行わず、保存された選択値も変更しない。

起動エラー画面では選択番号と言語も示し、待機時間の満了やEnter・Esc・Del・数字1/2/3によってLive Placeへ進まない。画面を自動消灯せず、通常の画面操作やログ記録の開始を許可しない。利用者が選択先のデータをSD上へ戻して再起動することで、起動時検証をやり直す。

この条件は起動時の選択先欠落に対する規則である。通常起動後に発生する地名検索エラーで記録中のGPSログを停止する規則ではない。既存のチャンク上限超過・索引確保失敗の利用不可処理とは理由を区別する。

## 9. 記述例

以下は形式の記述例であり、各言語の実ファイルが配布済みであることを示すものではない。

```ini
[dataset]
version=1
map=municipality.glc
default_language=ja

[ja]
title=日本・市区町村
description=市区町村単位の行政区域データ
wordbook=municipality-ja.giswordbook

[en]
title=Japan Municipalities
description=Municipality boundaries in Japan
wordbook=municipality-en.giswordbook
```
