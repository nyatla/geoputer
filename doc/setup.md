# Geoputer セットアップマニュアル

対象バージョン：v0.1.0

このマニュアルでは、Cardputer ADVにファームウェアを書き込み、microSDカードへマップセットを配置して、地名表示とGPS記録を使える状態にします。各画面の操作は[操作マニュアル](user-manual.md)を参照してください。

## 1. 用意するもの

- M5Stack Cardputer ADV
- GNSSを搭載したCap LoRa-1262とGPSアンテナ
- FAT32形式のmicroSDカード
- ファームウェア書込みに使う、データ通信対応のUSBケーブルとPC

GeoputerはCapのGNSSを使用します。LoRa無線機能は使用せず、外付けGPSはv0.1.0では利用できません。マップセットを入れなくてもGPSログは記録できますが、地名と区域境界の表示にはマップセットが必要です。

## 2. ファームウェアを書き込む

通常は[M5BurnerのGeoputer公開ページ](https://burner.m5stack.com/54NPB2)から書き込みます。Cardputer ADVをUSBでPCへ接続し、公開ページの案内に従ってGeoputerを選択してください。書込み後に端末を起動し、Geoputerの起動確認画面が表示されることを確認します。

M5Burner用の全体イメージを書き込むと、端末内部の設定は初期化されます。microSDカードのファイルは変更されません。M5Launcherと同じカードを使用する場合も、Geoputerのファイルは`/geoputer/`以下へ置きます。

BINを使った手動書込みが必要な場合は、[手動書込み](#8-binを使った手動書込み)を参照してください。

## 3. microSDカードを準備する

FAT32形式のカードを用意して端末へ挿入します。Geoputerが使用する基本ディレクトリは次のとおりです。

```text
/geoputer/
  dataset/    マップセット
  logs/       GPSログ
  export/     GPX・KML・CSVの書き出し先
```

FAT32カードにこの構成がない場合、端末は初期構成の作成を確認します。承諾すると不足しているディレクトリを作り、再起動します。既存の他のファイルはそのまま残します。PCで先に同じディレクトリを作成しても構いません。

カードがFAT32でない場合はフォーマットの確認が表示されます。**フォーマットするとカード全体のデータが消えます。** M5Launcherのファイルなどが入っているカードは、必要なデータを退避してから操作してください。承諾するとFAT32で初期化し、基本ディレクトリを作って再起動します。取消した場合はSDを必要とする機能を使えないまま起動します。

## 4. マップセットを選ぶ

[マップセットの概要](mapsets.md)で選び方を確認し、[マップセット仕様一覧](mapsets-spec.md)で対象地域と必要な区域の細かさを比較します。例として日本向けには次のセットがあります。

| 識別名 | 対象 |
|---|---|
| `jp-n03-y2026-1` | 都道府県・市区町村の行政区域 |
| `jp-est-y2020-2` | 町丁・字等と下位地区 |
| `jp-esc-y2026-2` | 海岸線を反映した小地区等 |

各マップセットは別々のZIPです。[GitHub Release v0.1.0](https://github.com/nyatla/geoputer/releases/tag/v0.1.0)から、選んだ識別名と同じ名前のZIPを取得します。たとえば`jp-n03-y2026-1`には`jp-n03-y2026-1.zip`を使います。

1つのZIPには、そのマップで使えるすべてのWordbookが入っています。日本の3セットは日本語と英語、その他のセットは英語を収録しています。画面の表示言語と地名に使うWordbookは別に選択します。

## 5. マップセットを配置する

ZIPと同じ識別名のフォルダを作り、**ZIPの中身をそのフォルダへ直接**展開します。ZIP内のファイルをさらに別のフォルダへ入れないでください。完成したフォルダをカードの`/geoputer/dataset/`へコピーします。

```text
/geoputer/dataset/jp-n03-y2026-1/
  dataset.ini
  map.glc
  N03-20260101.giswordbook
  N03-20260101.en.giswordbook
  README.md
  NOTICE-map.md
  NOTICE-en.md
```

`dataset.ini`と`map.glc`が識別名フォルダの直下にあることを確認してください。WordbookやNOTICEもZIPに入っているものをまとめてコピーします。複数のセットを使う場合は、それぞれ別の識別名フォルダに置きます。

カードを抜いてコピーするほか、動作モードを切り替えた後にUSBマスストレージやWi-Fi管理画面からファイルを配置することもできます。操作は[操作マニュアル](user-manual.md#7-usbとwi-fiでファイルを扱う)を参照してください。

## 6. 端末でマップセットを適用する

1. 通常画面で`0`を押して設定を開きます。
2. 「データセット選択」→「データセットを選択」へ進み、コピーした識別名を選びます。
3. 日本語と英語のWordbookがある場合は、「辞書／WORD」の行で左右キーを使い、`ja`または`en`を選びます。
4. 「適用する／Apply」を選び、索引の生成と確認が終わるまで待ちます。処理中は電源を切ったりカードを抜いたりしないでください。

**記録中または一時停止中はデータセットを切り替えられません。** GPS画面または`G`の操作でログを停止し、保存・終了が完了してから適用してください。

画面の日本語・英語は別設定です。日本語表示から英語へ切り替えるには`0`→「動作設定」→「表示言語」を開き、左右キーで`English`を選びます。別の項目へ移ると確定します。英語の地名も使いたい場合は、上記の「辞書／WORD」で`en`を選びます。

## 7. 初回の動作確認

空が見える場所でGPSアンテナを使用し、GPS画面（`3`）で測位状態を確認します。有効な測位になるまでは地名や座標が表示されないことがあります。現在地画面（`1`）で地名、地図画面（`2`）で区域境界を確認してください。ログはGPS画面の`Enter`または共通の`G`から開始できます。起動直後のログ状態は停止です。

問題がある場合は次を確認します。

| 表示・状態 | 確認すること |
|---|---|
| SDカードなし | カードの挿入と認識。GPS表示は使えてもログ保存とマップセット読出しは使えません |
| FAT32でない | カード内の必要なファイルを退避し、FAT32として準備する |
| データセット未選択 | `dataset.ini`と`map.glc`の配置を確認し、設定からセットを選ぶ |
| 選択済みセットが使えない | ファイルと索引を確認し、設定の「キャッシュ検証」または「キャッシュ再生成」を実行して再適用する |
| GPSが未測位 | アンテナ接続を確認し、空が見える場所で測位を待つ |

データセットに問題があってもGPS表示とログ記録は、SDなど個別の必要条件を満たせば利用できます。起動時の読込み前に設定を開きたいときは、Escを押したまま電源を入れるとメンテナンス画面へ進めます。

## 8. BINを使った手動書込み

配布BINには用途の違う2種類があります。通常の導入は上記のM5Burner公開ページを使用してください。

| ファイル | 用途 |
|---|---|
| `geoputer-v0.1.0-m5burner.bin` | 起動ローダー・パーティション表を含む全体イメージ。Flash先頭`0x0`へ書き込む |
| `geoputer-v0.1.0-standalone-0x10000.bin` | 対応する起動ローダー・パーティション表がすでにある端末の、アプリ領域`0x10000`だけを更新する |

M5Burnerへ登録するのは前者です。スタンドアロン版をFlash先頭やM5Burnerへ指定すると起動できません。esptoolで全体イメージを書き込む場合は、端末のポート名を指定します。

```sh
python -m esptool --chip esp32s3 --port PORT write_flash 0x0 geoputer-v0.1.0-m5burner.bin
```

`PORT`は実際のポート名へ置き換えてください。自動で書込みモードへ入らない場合は、Cardputer ADVのG0（BOOT）を押しながら電源をOFFからONへ切り替え、約1秒後にG0を離します。詳しいイメージ構成は配布物の`FLASHING.md`を参照してください。
